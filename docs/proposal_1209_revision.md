## 1. 評估議題 2–4：三項不需訓練的分析（第一折，2026-11-16）

使用者指示（2026-11-16）：`evaluation.pptx` 的五個議題裡，資訊來源、資訊時效、市場狀態三張圖還有假設值，
先做不需要訓練的三項：市場狀態分組、[24] 的台股版與合併版、[24] 的輸入延遲。

**範圍與限制**

- **只做第一折**（test 2024-12-26 ~ 2025-12-30，246 天）。教授指示：除了整體比較的結果表用到第二折，其餘議題以第一折為主。
- **baseline 的方法不動**（教授指示）。[24] 只換預測特徵，換法都是原文自己做過的對照（同市場對照 §5.2.2、合併來源 Appendix E、
  輸入時效 §5.4）；篩邊、視窗、重訓間隔、截尾、各模型超參數都照 `configs/tw50.yaml` 的 `baselines.bipartite`。
- **三項都是描述性分析**：第一折的 test 已經被看過很多次，這裡不主張新的顯著性結論，只把示意圖上的假設值換成實測值。
  判準在計算前寫下並記 SHA-256（1.8）；每項分析只跑一次。
- 沒有新的神經模型訓練。主結果、單市場消融、MEIG 都用既有的 run（`tw50_rgcnSA`、`tw50_smktSA`、`tw50_bl_meig`）。
- MAGNET 與 MEIG 的輸入延遲需要改資料層並訓練，不在本節，另外登記。

### 1.1 結論（先看這裡）

1. **市場狀態（議題 4）**：投影片上的兩句示意敘述都不成立，只有「IC 隨美股波動上升」成立。
   - 最平靜的一組，MAGNET − LASSO +0.0374，分不出差別（p 0.377）。「美股平靜時 MAGNET 仍保有預測力、[24] 較弱」不能寫。
   - 波動最大的一組是 LASSO 較高（MAGNET − LASSO −0.0589，p 0.032；未做多重校正，五組一起校正後不顯著）。
     「美股大幅波動時兩者接近」不能寫。
   - MAGNET 與 LASSO 的逐日 IC 都隨美股波動上升（Spearman +0.200 / +0.250，p 0.0017 / 0.0001）；單市場版本是平的（−0.021）。

3. **[24] 的資訊時效（議題 3）**：LASSO 落後 1 / 2 / 3 / 4 天的 IC 是 +0.1042 / −0.0118 / +0.0167 / +0.0357。

     三個延遲一起做 Holm 後不顯著（0.051），不解讀。

### 2.1 結論（先看這裡）

1. **MAGNET 的跨市場訊號集中在最近一個美股交易日**（登記的判讀 a）。美股輸入落後 1 / 2 / 3 / 4 天的 IC 是
   +0.1127 / +0.0274 / +0.0246 / +0.0267。落後 1 天 − 落後 2 天 +0.0853（HAC p 9.6e-07，Holm 1.8e-06）；
   10 顆種子每一顆都是落後版本較低。
2. **美股輸入落後 2 天以上時，MAGNET 與完全不用美股分不出差別**（登記的判讀 b）。落後 2 / 3 / 4 天 − 單市場消融（+0.0250）
   是 +0.0024 / −0.0004 / +0.0017（p 0.52 / 0.88 / 0.63，Holm 都是 1.0）。RankIC 也一樣（+0.0587 / +0.0554 / +0.0582 對 +0.0587）。
   也就是說，MAGNET 相對於單市場版本的增益（+0.088）全部來自前一晚的美股；過時的美股資訊沒有貢獻，也沒有造成傷害。
3. **曲線不是平滑衰減，是一步掉到底**：落後 2 天就已經在單市場的水準，落後 3、4 天沒有再下降。這和 [24] 的形狀一致
   （§1.4：落後 2 天直接掉到 0 附近）。兩者掉到的位置不同，是因為 MAGNET 還有台股自己的輸入，[24] 只有美股。

### 2.2 做法

**延遲的定義**。`us_lag = l` 時，美股層輸入 `x_seq_L1` 的視窗往過去移 l − 1 列（每檔美股各自的交易日），最後一列是 target_date
之前倒數第 l 列。l = 1 就是原本的行為。不變的東西：

- 台股層輸入 `x_seq_L2`（仍是 t−1 為止）、標籤、兩層的邊（快照裡的圖，用到 t−1 為止的資料建）。
- 這對應 [24] 原文 §5.4 的做法：圖仍用 t−1 建，預測特徵換成 t−l。與 §1.4 的 `bipartite_screen.py --lag` 是同一個定義，
  已逐樣本核對（T = 1、`us_lag = l` 的輸入，等於 T = l、`us_lag = 1` 的第 −l 列）。
- MAGNET 耦合層的美股市場因子是在模型裡由 `x_seq_L1` 算出來的，所以跟著一起落後；沒有任何美股輸入留在 t−1。

**怎麼讀這個實驗**。MAGNET 的台股層輸入仍是 t−1 的台股報酬，而台股在 t−1 已經反映了美股 t−2 之前的資訊。
所以延遲版的參考下限是單市場消融（+0.0250），不是 0；判讀 b 就是在問延遲版有沒有高於這條線。

**可以寫**

- 「把美股輸入換成落後 2 天以上，MAGNET 的第一折 IC 從 0.113 降到 0.025–0.027，與完全不用美股的單市場版本分不出差別。

## 3. 台股 universe 的定義與存活偏誤（查證，2026-11-18）

口試可能會被問：50 檔台股是不是用「現在的」成分股回頭選的（倖存者偏差）。這節只查證既有的定義，沒有改資料或重跑。

### 3.1 結論（先看這裡）

1. **名單在樣本開始前就固定了**，不是用現在的成分股回頭選。用的是 2019-01-02 適用的臺灣 50 指數成分股。
   這份名單由 2018-12 的定期審核決定，2018-12-21 生效。
2. **兩個來源互相驗證，50/50 完全一致**：
   - 公開資訊觀測站上元大台灣卓越 50（0050）民國 107 年第 4 季的基金持股明細（期末 2018-12-31）。
     0050 採完全複製法，期末持股就是指數成分股。
   - `scripts/tw50_rollback.py` 從 2025-09-30 的現行名單出發，依 `configs/universe/tw50_change_log.json` 撤銷 24 次審核，
     回推到 2019-01-02。每一步都檢查不變量，結果存在 `configs/universe/tw50_constituents_reconstructed.json`。
3. **有一個存活偏誤的例外：2823 中壽。**
   - 它是 2018Q4 的成分股，2021 年併入開發金（2883）後下市，所以被移出 universe。
     原因是模型的節點集在整個樣本期固定，無法表示會變動的成員。
   - 影響範圍是 51 檔中的 1 檔，而且它的經濟曝險由同在 universe 內的 2883 吸收。
     `configs/universe/universe_tw_2019.json` 的 `delistings` 欄已記錄這件事，但在本次之前，proposal 與 `docs/experimental_setup.md` 都沒有寫出來。
4. **補進來的是 8150 南茂。** 它不是 TW50 成分股，是為了 ADR 配對（IMOS）加的。
   挑它看的是「雙掛牌」這個事實，在 2019-01-02 前就確定，不是依績效。
   所以 50 檔的實際組成是 **49 檔 2018Q4 成分股，加 1 檔配對股**。
5. 產業類別（主結果的同產業關係圖用的）取自同一份 2018Q4 持股明細，在整個樣本期固定。

**可以寫**：台股 universe 是樣本開始前確定的 2018Q4 臺灣 50 成分股，以兩個來源驗證。
只有 1 檔因為樣本期內下市而排除，已揭露，它的曝險由同集團的 2883 保留。

**不可以寫**：「完全沒有倖存者偏差」。選取規則本身要求「於樣本期內持續掛牌」，2823 就是因為這條被排除的。
