## 1. 評估議題 2–4：三項不需訓練的分析（第一折，2026-11-16）

使用者指示（2026-11-16）：`evaluation.pptx` 的五個議題裡，資訊來源、資訊時效、市場狀態三張圖還有假設值，
先做不需要訓練的三項：市場狀態分組、[24] 的台股版與合併版、[24] 的輸入延遲。

**範圍與限制**

- **只做第一折**（test 2024-12-26 ~ 2025-12-30，246 天）。教授指示：除了整體比較的結果表用到第二折，其餘議題以第一折為主。
- **baseline 的方法不動**（教授指示）。[24] 只換預測特徵，換法都是原文自己做過的對照（同市場對照 §5.2.2、合併來源 Appendix E、
  輸入時效 §5.4）；篩邊、視窗、重訓間隔、截尾、各模型超參數都照 `configs/tw50.yaml` 的 `baselines.bipartite`。
- **三項都是描述性分析**：第一折的 test 已經被看過很多次，這裡不主張新的顯著性結論，只把示意圖上的假設值換成實測值。
  判準在計算前寫下並記 SHA-256（1.8）；每項分析只跑一次。
- 沒有新的神經模型訓練。主結果、單市場消融、MEIG 都用既有的 run（`tw50_rgcnSA`、`tw50_smktSA`、`tw50_bl_meig`）。
- MAGNET 與 MEIG 的輸入延遲需要改資料層並訓練，不在本節，另外登記。

### 1.1 結論（先看這裡）

1. **市場狀態（議題 4）**：投影片上的兩句示意敘述都不成立，只有「IC 隨美股波動上升」成立。
   - 最平靜的一組，MAGNET − LASSO +0.0374，分不出差別（p 0.377）。「美股平靜時 MAGNET 仍保有預測力、[24] 較弱」不能寫。
   - 波動最大的一組是 LASSO 較高（MAGNET − LASSO −0.0589，p 0.032；未做多重校正，五組一起校正後不顯著）。
     「美股大幅波動時兩者接近」不能寫。
   - MAGNET 與 LASSO 的逐日 IC 都隨美股波動上升（Spearman +0.200 / +0.250，p 0.0017 / 0.0001）；單市場版本是平的（−0.021）。
2. **[24] 的資訊來源（議題 2）**：LASSO 只用台股 +0.0225、只用美股 +0.1042、美股 + 台股 +0.0987。
   - 只用美股 − 只用台股 +0.0818（p 0.0001）：跨市場資訊對 [24] 的價值很明確。
   - 美股 + 台股 − 只用美股 −0.0056（p 0.35）：加入台股沒有增量。
   - **圖上的標籤要改**：主表的 [24] 是「只用美股」，示意圖把它標成 TW + US 是錯的；[24] 要畫成三種來源。
3. **[24] 的資訊時效（議題 3）**：LASSO 落後 1 / 2 / 3 / 4 天的 IC 是 +0.1042 / −0.0118 / +0.0167 / +0.0357。
   - 落後 2 天與 0 分不出差別（p 0.41）。依登記：寫「[24] 用到的跨市場訊號只在最近一個美股交易日」。
   - 真實曲線不是平滑衰減：落後 2 天直接掉到零附近，之後略微回升。落後 4 天單看顯著（p 0.017），
     三個延遲一起做 Holm 後不顯著（0.051），不解讀。
4. **改過的 [24] 程式以預設值重跑，10 個模型的 IC 與 RankIC 全部重現主表**；LASSO 的預測與既有 run 最大差 1e-16。
5. 三張圖（`scripts/gen_discussion_figures.py`）還沒有換成實測值。
