## 為什麼要凍結

第 1 階段的 universe 擴充會改變節點順序、張量形狀與 A12 的建構方式
(從嚴格對角改為稀疏索引映射)。改完之後:

- 現有 `data/graphs/snapshots/` 的 1,644 個快照不再與新程式碼相容
- 所有既有 run 的數字失去可比性
- **無法再證明「重構沒有偷偷改變模型語意」**

因此在動任何程式碼之前,先把現況固定成可機器驗證的基準。

全部模型擠在 test_IC 0.011-0.033,range 大幅互相覆蓋。

### 2. 全配對顯著性檢定(M8)

7 個 family 兩兩共 21 組,同 seed 同測試日配對 daily IC(n ≈ 735/組),Holm 校正。

**存活 0 / 21。** 最小 raw p = 0.2687(MEIG-core − MAGNET@1e-3),
連未校正的 p < 0.05 都無一組達標。

### 3. 噪音下界(M8 實驗 5)

| k | 實測 σ(daily IC) | 理論 1/√(k−1) |
|---|---|---|
| 7 | 0.404 | 0.408 |

實測值與零訊號理論下界逐點吻合——噪音是 7 檔橫截面的先天極限,不是模型缺陷。

- 分辨 ΔIC = 0.02 需約 **41 檔**;ΔIC = 0.01 需約 **158 檔**(固定 246 測試日)
- run 層級標準差 **σ_run ≈ 0.027**(M8 Part E,同 seed 同 config × 5)
- 單 run 246 日 mean IC 的理論 SE 亦為 ~0.026——兩個獨立噪音尺度同量級

### 4. Level R² 與組合指標(M10,67 個 run 回算)

- **level R² 全部為負**:中位數 −0.035,最佳 −0.0002,最差 −2.51
- 零預測器(ŷ ≡ 0)的 R²_zero **恰為 0**,贏過表上所有模型,但 IC 未定義
- RMSE 僅高於 std(y) 1.7%,平方放大後即 R² = −0.035
- 隨機預測器的 Sharpe **std ≈ 1.03**(2000 次蒙地卡羅,p90 = +1.38, p95 = +1.70)
- MAGNET 的 Sharpe SD = 1.171,與純噪音同級

## E7 驗收條件(重構之後必須通過)

把 universe 設回本文件記錄的 7 對,重跑,執行:

```bash
.venv/bin/python scripts/freeze_k7.py --verify
```

| 路徑 | 判準 | 理由 |
|---|---|---|
| `baseline_lstm` / `baseline_early_fusion` | predictions CSV 的 **SHA-256 完全相同** | 純 LSTM 路徑,同 seed 位元確定 |
| MAGNET 等 GNN 路徑 | test_IC 落在 ±3σ_run(±0.081)內 | MPS scatter 非位元確定 |

**位元確定的那 10 個 run 是硬證據**——若 SHA-256 對不上,代表重構改變了
資料組裝或模型語意,必須先查清楚再繼續,不得以「差異很小」帶過。

## 已知限制(誠實記錄,擴充時要一併處理)

1. **單一測試窗**(246 天,2024-12 至 2025-12)。無 rolling-origin,結果可能受期間影響。
2. **7 檔全部同產業**(半導體為主),橫截面同質性高。
3. **100% 配對率**是迷你 universe 的產物,非真實市場樣貌。
4. **測試集已被觀看多次**(79 個 run)。MAGNET 的 config 是在看過 test 的情況下選的,
   EF 則未經任何調參——這個不對稱對 EF 不利,故 EF 的勝出是保守估計。
5. `data/graphs/snapshots/` **不可覆寫**。擴充後的快照請寫入新目錄
   (如 `data/graphs/snapshots_tw50/`),否則 E7 無法執行。
