## 2. 診斷主線：資訊在哪裡流失

以 per-target ridge 量各位置可線性抽取的 test IC（協定同 ridge_ladder）：

```
原始 3 特徵（3 x 30 = 90 維）                      +0.0874
耦合點 h_L1（基準）                                +0.0448   <- 編碼器丟掉 49%
耦合點 h_L1（BN 拼接，訓練後）                       +0.0693 ~ +0.0754
模型實際輸出（BN 拼接）                              +0.0439
```

兩個 gap：
- **Gap A** 編碼器（LSTM -> GAT_L1 -> proj_L1）丟掉約一半 —— BN 拼接修回大部分
- **Gap B** 模型只用掉耦合點的 60~71% —— 尚未動過

## 3. 已排除的假說（不要重做）

| 假說 | 結論 | 依據 |
|---|---|---|
| 表示塌縮（cos=1.0）是缺陷，拆開它會變好 | **推翻** | cs_demean 去共同成分 IC +0.0269 -> -0.0021；共同成分佔 h_L1 能量 99.97% |
| 可達性 7/50 是瓶頸 | **推翻** | dense A 做到 50/50，無改善；模型在無約束下把稠密邊縮到初始值的 13% |
| RSI_14 / BB_pos 恆為正造成共線，是負擔 | **推翻** | 拿掉後 IC 掉 45%，合併檢定 Mann-Whitney p=0.0020。它們是唯二的有界水準型特徵 |
| 特徵愈少愈好（線性階梯的排序會轉移） | **推翻** | 1/2/4/7 維彼此無差異（ANOVA p=0.9622），關鍵是有沒有 RSI+BB |
| 加法式跳接能把 raw 送進耦合點 | **推翻** | 耦合點 +0.0448 -> +0.0446。相加把 raw 壓進已被佔滿的 d' 維，不可分 |

### 兩個實作層的教訓

1. **上限測試必須用模型實際會用的算子鏈。** 曾把「拼接」的上限（+0.0662）
   誤當成「相加」的，導致 2a 白跑一輪。
2. **LayerNorm 不可用於特徵軸的正規化。** F=3 時它把 3 個數字壓到剩 1 個
   自由度，跳接路徑 raw +0.0874 -> +0.0332（掉 62%）。2a 與 2a' 兩次實驗
   因此都不算數。正確算子是逐特徵跨節點（`_FeatureNorm`，BatchNorm 語意）。
   `norm="none"` 也不行（掉 45%，尺度導致條件數問題）。

## 4. 實驗紀律（本專案的判讀標準）

sigma_seed = 0.0062（IC，兩組各 10 顆種子獨立量到同一值）。

| 每組 n | MDE（80% 檢定力） | 無母數雙尾 p 下限 |
|---:|---:|---:|
| 3 | 0.0188 | 0.10（永遠無法顯著） |
| 5 | 0.0125 | 0.0079 |
| 10 | 0.0082 | 0.0002 |
| 20 | 0.0056 | — |

用專案自己的兩組 10 顆種子窮舉 14,400 個「只跑 3 顆」的平行實驗：

- 符號錯誤 10.4%（IC）
- 檢定力 5.8%，而自己比自己的偽陽性率 6.0% —— **兩者相同，n=3 對這個量級不產生證據**
- 顯著時效果量誇大 2.26x（實際在 BN 跳接上驗證為 1.41x）

**規則：3 顆探路只看方向；下結論前補到 10 顆；效果量 < 0.01 一律寫「無法區分」。**
`scripts/paired_daily.py` 會自動標記「無結論」。

## 5. 後續實驗順序

### 優先度 1 —— 在新前提下重測（前提已改變，成本低）

| # | 實驗 | 為什麼 | 成本 |
|---|---|---|---|
| 1.1 | 跳接拉回 F9（9 特徵） | 「9 維 vs 3 維」的比較是在 LayerNorm bug 下做的 | 3+7 seed |
| 1.2 | `bnboth` 補到 10 顆 | n=3 時 IC 較差、RankIC 較好，無結論 | 7 seed |
| 1.3 | 重測 dense A（搭配 BN 跳接） | dense A 在耦合點只有 +0.0448 時失敗，現在是 +0.075 | 3+7 seed |
| 1.4 | 重測 cs_demean（搭配 BN 跳接） | 同上；共同成分不再是唯一可用訊號 | 3 seed |

### 優先度 2 —— 縮小 Gap B（模型只用耦合點的 6~7 成）

| # | 實驗 | 假說 |
|---|---|---|
| 2.1 | gate 診斷與改造 | 實測 gate 為常數 0.5075、跨節點 std 0.0044，完全沒分化 |
| 2.2 | 預測頭加寬 / 換非線性 | p18 寫 GELU 但碼是 ReLU；head 僅 2,177 參數 |
| 2.3 | rank loss 的 `rank_normalize` 在新設定下重測 | 舊測試在 LayerNorm 前提下做的 |

### 優先度 3 —— 縮小 Gap A 的剩餘部分（+0.0754 -> +0.0874）

| # | 實驗 | 假說 |
