## 1. 目前的最佳 MAGNET 設定（但不是最佳神經模型）

> **2026-08-23：主結果 arm 由 `tw50_T1F3bnl1` 換成 `tw50_inbnw_noskip`。**
> 拼接跳接的增益已證實由前處理缺陷造成：把逐特徵正規化移到 LSTM 之前後，
> 跳接的增量由 +0.0234（逐日與跨種子雙雙通過 Holm）掉到 +0.0060（皆不顯著）。
> 新 arm 拿掉跳接、只改正規化位置與優化器，IC +0.0475 -> +0.0517、
> 種子 sd 0.0180 -> 0.0021。完整判讀見 `docs/proposal_819_revision.md` §12-16。
> 代價：RankIC +0.0513 -> +0.0351，且逐日檢定的檢定力下降（見 §1.1）。

```

features       log_return, RSI_14, BB_pos      （feature_subset，3 維）
T_history      1
gat.num_layers 1
lstm.input_norm  batchnorm       <- 逐特徵跨節點，放在 LSTM 之前
raw_skip       無
training.optimizer  adamw        <- 解耦 weight decay
tag            tw50_inbnw_noskip
```

### 1.1 換基準的代價：逐日檢定的檢定力

同一組對照，換基準前後：

| 對照 arm | 舊基準 dIC / 逐日 p / 跨種子 p | 新基準 dIC / 逐日 p / 跨種子 p |
|---|---|---|
| MAGNET F3（無跳接） | +0.0234 / **0.0008** / 0.0026 | +0.0277 / 0.0760 / **0.0000** |
| MAGNET F9 T=1 L=1 | +0.0216 / **0.0052** / 0.0042 | +0.0258 / 0.1105 / **0.0000** |
| 稠密耦合 A | +0.0288 / **0.0016** / 0.0484 | +0.0330 / 0.0620 / **0.0002** |
| RC 常數對照 | +0.0326 / **0.0171** / — | +0.0369 / 0.0580 / — |

**效果量全部變大，跨種子 p 全部變強，但逐日 p 全部變弱。**
原因是 `r_day`：舊基準與這些對照是「同一個訓練設定 ± 一條路徑」，
逐日 IC 序列相關 0.80，配對能消掉大部分噪音；新基準同時改了輸入正規化
與優化器，`r_day` 掉下來，配對就幫不上忙。這是 `paired_daily.py`
說明文字裡已寫明的情況。

**須主動揭露：RC 常數對照的逐日 p 由 0.0171 升到 0.0580，跨過 0.05。**
RC 沒有種子，逐日是唯一可用的檢定，所以這一列現在不顯著。
兩個版本其實都不算舒服（0.017 也只是勉強），這是既有的弱點被放大，
不是換基準造成的新缺陷——但口試若被問到必須照實回答。

### 但 MAGNET-v2 不是最佳神經模型（2026-08-17 更新）

Early fusion（輸入層直接拼接配對 ADR 特徵，無跨層耦合、無 gate）補到
10 顆種子後：

| 指標 | EF | MAGNET-v2 | 差 (v2−EF) | 95% CI | Welch | 配對 t | Mann-Whitney | Wilcoxon | v2 勝 |
|---|---:|---:|---:|---|---:|---:|---:|---:|---:|
| IC | +0.0518 | +0.0475 | −0.0043 | [−0.0177, +0.0090] | 0.477 | 0.481 | 0.678 | 0.492 | 4/10 |
| RankIC | +0.0412 | +0.0513 | +0.0101 | [+0.0011, +0.0191] | 0.038 | 0.032 | 0.104 | 0.049 | 7/10 |

**分歧判決。** IC 上 EF 仍較高且贏 6/10 顆（不顯著，p=0.48）；RankIC 上 v2 較高，
兩個母數檢定與 Wilcoxon 過 5%（0.049 恰在邊界），但 Mann-Whitney 重評後
**從 0.064 退到 0.104**。RankIC 這一項修正後是變弱而非變強，且各檢定彼此不一致。

公平性已處理：EF 在 MAGNET-v2 的輸入設定（T=1, F=3, L=1）下崩到 −0.0076
（對其原設定 p<0.001），故兩者各以自身最佳設定比較。

**目前可以宣稱與不可以宣稱：**

| 可以說 | 依據 |
|---|---|
| 跳接顯著改善 MAGNET | +0.0234，四種檢定全過，8/10 種子（修正後變強） |
| MAGNET-v2 顯著勝過六個文獻 baseline 與原始 MAGNET | +0.0414, p=0.048 |
| MAGNET-v2 在 RankIC 上優於 early fusion | **修正後更弱**：MW p=0.104，Wilcoxon 0.049，不宜再當作可宣稱項 |

| 不可以說 | 為什麼 |
|---|---|
| MAGNET 的多重圖耦合與 gate 是必要的 | 無圖耦合的輸入層拼接在 IC 上追平甚至更高 |
| MAGNET-v2 是最佳神經模型 | EF 的 IC 點估計較高，且贏 6/10 顆種子 |
| 任何相距 0.005 以內的排名 | 選點仍在 MPS 噪音下決定，須以 eval_device=cpu 重跑後才算數 |

## 3. 已排除的假說（不要重做）

| 假說 | 結論 | 依據 |
|---|---|---|
| 表示塌縮（cos=1.0）是缺陷，拆開它會變好 | **推翻** | cs_demean 去共同成分 IC +0.0269 -> -0.0021；共同成分佔 h_L1 能量 99.97% |
| 可達性 7/50 是瓶頸 | **推翻** | dense A 做到 50/50，無改善；模型在無約束下把稠密邊縮到初始值的 13% |
| RSI_14 / BB_pos 恆為正造成共線，是負擔 | **推翻** | 拿掉後 IC 掉 45%，合併檢定 Mann-Whitney p=0.0020。它們是唯二的有界水準型特徵 |
| 特徵愈少愈好（線性階梯的排序會轉移） | **推翻** | 1/2/4/7 維彼此無差異（ANOVA p=0.9622），關鍵是有沒有 RSI+BB |
| 加法式跳接能把 raw 送進耦合點 | **推翻** | 耦合點 +0.0448 -> +0.0446。相加把 raw 壓進已被佔滿的 d' 維，不可分 |
| 多重圖耦合與 gate 是跨市場預測的必要結構 | **未獲支持** | Early fusion（輸入層拼接，無耦合無 gate）IC +0.0518 vs v2 +0.0475，贏 6/10 顆種子 |
| baseline 沒調過才輸給我們 | **推翻** | EF 在 v2 的調校設定下崩到 −0.0076；兩者需要不同輸入 regime，各以最佳設定比較後 EF 仍較高 |

### 兩個實作層的教訓

1. **上限測試必須用模型實際會用的算子鏈。** 曾把「拼接」的上限（+0.0662）
   誤當成「相加」的，導致 2a 白跑一輪。
2. **LayerNorm 不可用於特徵軸的正規化。** F=3 時它把 3 個數字壓到剩 1 個
   自由度，跳接路徑 raw +0.0874 -> **+0.0311**（掉 64%）。2a 與 2a' 兩次實驗
   因此都不算數。正確算子是逐特徵跨節點（`_FeatureNorm`，BatchNorm 語意），
   線性探針量到 +0.0874，與未正規化的原始特徵**逐位相同**——逐特徵標準化
   是每個特徵一個仿射映射、對所有節點相同，線性模型本來就吸收得掉，
   所以它在資訊上零損失。`norm="none"` 資訊同樣無損但模型實測較差，
   原因是尺度差 5000 倍造成線性層條件數問題，屬最佳化而非資訊問題。
   （2026-08-17 重測，`scripts/ridge_ladder.py` 同協定；先前記為 +0.0332
   的數字有誤。）

sigma_seed = 0.0062（IC，兩組各 10 顆種子獨立量到同一值）。

| 每組 n | MDE（80% 檢定力） | 無母數雙尾 p 下限 |
|---:|---:|---:|
| 3 | 0.0188 | 0.10（永遠無法顯著） |
| 5 | 0.0125 | 0.0079 |
| 10 | 0.0082 | 0.0002 |
| 20 | 0.0056 | — |

用專案自己的兩組 10 顆種子窮舉 14,400 個「只跑 3 顆」的平行實驗：

- 符號錯誤 10.4%（IC）
- 檢定力 5.8%，而自己比自己的偽陽性率 6.0% —— **兩者相同，n=3 對這個量級不產生證據**

**規則：3 顆探路只看方向；下結論前補到 10 顆；效果量 < 0.01 一律寫「無法區分」。**
`scripts/paired_daily.py` 會自動標記「無結論」。

## 5. 後續實驗順序

### 優先度 0 —— 回答「為什麼簡單拼接不輸」（2026-08-17 新增，最高優先）

Early fusion 的結果讓這變成本專案最重要的未解問題。三個實驗都是診斷取向，
成本低，且不論結果如何都有論文價值。

| # | 實驗 | 假說 / 為什麼 | 成本 |
|---|---|---|---|
| 0.1 | EF 的 val/test 落差診斷 | EF val +0.1013 -> test +0.0518（落差 0.050）；v2 是 +0.0653 -> +0.0475（0.018）。EF 過擬合嚴重得多，若加正則化或改早停可能更好也可能更差 | 純分析 + 3 seed |
| 0.2 | EF 的耦合點資訊量 | 用同一支 ridge 探針量 EF 的表示。若 EF 的可抽取資訊高於 v2 的 +0.0754，那 MAGNET 的編碼路徑是淨損失 | 純分析 |
| 0.3 | EF + raw skip | 跳接是否也能改善 EF。若能，跳接的貢獻與架構無關，論文的主張要改寫成「跳接有效」而非「MAGNET-v2 有效」 | 3+7 seed |

**0.3 是其中最關鍵的。** 目前 raw skip 的 +0.0234 是在 MAGNET 上測的；
若它在 EF 上也成立，那本工作的貢獻是一個可移植的元件，不是一個架構。

## 6. 論文層面的待辦

- **不依賴種子的確定性證據**是主證據，應優先成圖：
  43/50 節點跨市場輸入位元為零、h_L1 共同成分佔 99.97% 能量、
  lambda=1e-3 讓候選邊只送出 0.08%、模型主動把稠密邊縮到 13%、
  RSI_14 與 BB_pos 造成輸入層 +0.9800 共線（去掉後 +0.3273）。
- 簡報 p18 的 GELU/ReLU 與損失權重 1:0.5（實際梯度 1:3）須更正。
- `build_model` 把 `weak_links.mode` / `coupling.mode` 注入局部 cfg，
  `config_snapshot.yaml` 沒記錄到 —— 重現性缺口，應補。
- **MPS 非確定性（2026-08-18 已修）。** 2026-08-18 之前的 metric 全部算在
  MPS 上，同一份 best.pt 重評的 test IC 全距 0.0169，與跨 seed sd 同量級。
  已改為 `eval_device: cpu` + 每個 run 自我驗證 + 3 個迴歸測試。
  論文須揭露：現有數字是「對已選定 checkpoint 的正確重評」，但**選點**
  當初仍是用 MPS 的 val IC 決定的。要主張任何相距 0.005 以內的排名，
  必須先用 `eval_device: cpu` 從頭重跑該 arm。
  另：`mlflow.source.git.commit` 記的是 d0ecf76，但 2026-08-16 那批 run
  實際跑的是尚未 commit 的工作區程式碼（後來成為 b0f4fbd）——
  run 與 commit 的對應不可信，應在跑實驗前先 commit。
- 六個文獻 baseline 各只跑一組預設超參，MAGNET 跑了約 50 組。
  這是最大的公平性缺口，審查者會先問。Early fusion 已補到 10 顆種子
  並加測同設定版本，其餘五個尚未。
- **論述須改寫。** 原本的主張是「多重圖架構有效」；目前證據只支持
  「raw skip 這個元件有效」與「MAGNET-v2 勝過六個文獻 baseline」。
  在優先度 0.3 跑完之前，不可寫「耦合與 gate 是必要的」。
