## 0. 先講三件最重要的

1. **簡報描述的模型不是被評估的模型。** p23 的 `MAGNET (current) +0.0439`
   是 F3 + 拼接式原始特徵跳接（raw skip）的成績，而跳接在 p14 流程圖、
   p15 Phase 1、Algorithm 1、p22 環境設定裡**一個字都沒出現**。這是全份
   簡報最嚴重的落差：本專案唯一在統計上站得住的改動沒有被寫進架構。

2. **p22 呈現為「調參成果」的兩項改動，在驗證集上都是 null。**

   | 改動 | val IC 差 | val 配對 t | test IC 差 | test 配對 t |
   |---|---:|---:|---:|---:|
   | T = 20 → 1 | −0.0001 | 0.935 | +0.0054 | 0.020 |
   | F = 9 → 3 | −0.0016 | 0.251 | −0.0004 | 0.887 |
   | **raw skip off → on** | **+0.0340** | **0.0002** | **+0.0191** | **0.025** |

   （各 10 顆種子，同種子配對）。T 與 F 兩列在驗證集上完全分不開，
   卻在簡報上以 test IC 的高低呈現為選擇依據——口試時會被問
   「你怎麼選 T=1 的」，而目前投影片給的答案是 test IC，這是協定問題。
   真正被驗證集選出來的只有跳接（val 10/10 顆種子全勝）。

3. **例子與圖都已有實測數值可用。** 第 1 節給出 2025-04-10 這一天
   逐階段的實際張量數值，第 2 節給出 p14 的新版規格。不需要畫示意圖，
   直接用真的數字。

## 1. 建議一：一個貫穿三階段的例子

### 1.1 選定日期：2025-04-10（預測 4/10 當天的台股報酬）

挑選理由與揭露：這是 test 期間 ADR 波動最大的一天（前一交易日 TSM
+11.60%），選它是為了讓數值在投影片上看得清楚，**不是因為它有代表性**。
該日 day IC +0.2078，而全 test 期平均 +0.0427（s42）。這句話要寫在頁面
下緣，口試委員一定會問。

備用例子（若想要一個下跌日）：2025-04-07，TSM −6.96% → 2330 預測第 50 名、
實際第 47 名、實際報酬 −10.51%，day IC +0.3879。

### 1.2 模型在這一天看到什麼

4/9 美股收盤（台北時間 4/10 清晨 4:00），30 檔美股平均 +11.82%，

### 1.3 Phase 1（以 TSM 節點為例）

| 步驟 | 形狀 | 實測 norm | 備註 |
|---|---|---:|---|
| 輸入 x（T=1, F=3） | 3 | 42.49 | [+0.1160, 42.49, +0.3153] |
| Shared LSTM | 64 | 1.27 | 兩層共用同一份權重 |
| GATv2（1 層 4 head, \|ρ\| 當邊特徵） | 64 | 0.22 | 全 test 平均，LSTM 平均 1.54 |
| Type projection + LayerNorm | 29 | 3.65 | **不是 32** |
| **raw skip**：`_FeatureNorm(3)` → `Linear(3,3)` | 3 | 1.16 | 值 [+0.955, −0.641, −0.104] |
| `h_L1 = concat(proj, skip)` | **32** | 3.83 | 跳接佔能量 9.1%（全期平均 1.3%） |

**這張表本身就是投影片上最有說服力的一頁**，因為它同時解釋了跳接為什麼
必要。把節點之間的平均餘弦相似度加上去（全 246 個 test 日）：

| 表示 | 節點間平均餘弦 |
|---|---:|
| 投影出來的 29 維 | **+0.999968**（min +0.9998） |
| 跳接的 3 維 | +0.3243 |
| 合起來的 h_L1（32 維） | +0.9921 |
| h_L2（無跳接） | +0.9993 |

也就是說：**編碼器輸出的 29 維，對 30 檔美股而言幾乎是同一個向量；
耦合點上全部的橫截面資訊都由那 3 維跳接攜帶，而它只佔 1.3% 的能量。**
這一句是整個 Phase 1 的重點，比目前 p15 的「Core spirit: make Phase 2
fusion meaningful」具體得多。

### 1.6 把例子從軼事變成證據（建議獨立一頁）

單日例子一定會被問「你是不是挑過」。用全 246 天的統計回答：

| 統計量（246 個 test 日，s42） | 值 |
|---|---:|
| 7 檔配對股：ADR 報酬 vs **模型預測** 的日內 Spearman | **+0.687**（240/246 天為正） |
| 7 檔配對股：ADR 報酬 vs **實際報酬** 的日內 Spearman | **+0.095**（143/245 天為正） |

這兩個數字放在一起是本工作最誠實也最有力的一句話：

> The architecture transmits the ADR signal almost perfectly (+0.687).

它同時回答了「機制有沒有在動」與「為什麼 IC 只有 0.044」，並且自然
接到 Planned improvement。

### 1.7 p15 改寫（移除 Step 1/2/3）

教授要求拿掉 Step 的切分。建議把 p15 從「三個 Step 的清單」改成
「一條資料流 + 一個節點的實際數值」：

```
Phase 1: Dual-market encoding
One node, one day: TSM on 2025-04-09 (US close)

  x = [log_return +0.1160, RSI_14 42.49, BB_pos +0.3153]     R^{1x3}
        |                                               \
        | shared LSTM (H=64, one set of weights            \  raw skip
        |   for both markets)                               \  feature-wise norm
        v                                                     \  then Linear(3,3)
      GATv2, 1 layer, 4 heads, |rho| as edge attribute          \
        27 US neighbours on this day                             \
        |                                                         |
        v                                                         v
      Linear -> GELU -> LayerNorm  (29 dims)                  (3 dims)
        \______________________ concat ______________________/
                                |
                                v
                        h_1(TSM) in R^32   -> Phase 2

  Why the skip: without it the 29 projected dims have cosine +0.99997
  across all 30 US nodes. The 3 skip dims carry 1.3% of the energy and
  all of the cross-sectional information.
```

Algorithm 1 對應要加兩行：

```
7:  r_1 <- W_s · FeatureNorm(X_1[:, T])       # raw skip, no bias
8:  h_1 <- [ LayerNorm(GELU(P_1 · z_1)) ; r_1 ]
```

並在 Output 把維度寫成 `h_1 ∈ R^{n1 x d'}, d' = d_proj + d_raw = 29 + 3`。

## 4. Planned improvement 兩頁的內容（2026-08-18 重寫）

**本節已依 §8/§9 的秩量測全面改寫。** 舊版把瓶頸歸給「編碼器丟失資訊」與
「融合破壞秩」，兩者都不正確：編碼器忠實傳遞了一個 rank-1 的輸入，
融合反而讓秩微升。正確的因果鏈見下。

### p24 — Planned improvement (1/2)

> **2026-08-24：本頁已作廢，改用 §20 的探針資訊階梯。**
> 秩的敘事被 §19.3 推翻——F1 的表示秩 1.023 而探針值 +0.0955，
> F3 的秩 1.534 而探針值 +0.0822，秩低的資訊反而多。
> 以下保留為修改紀錄，不要拿去做投影片。

標題：`The bottleneck is cross-sectional rank, and it starts at the input`

2. **全模型只有兩個運算子在製造秩**：跳接裡的 BN_F、預測頭的 ReLU。

3. **秩在耦合這一步掉最多**（1.69 → 1.05），因為 43 個台股槽位只拿到

### p25 — Planned improvement (2/2)

標題：`Four changes to MAGNET, ordered by where rank is created or lost`

| # | 改動 | 檢驗的假說 | 預期效果 | 成本 |
|---|---|---|---|---|
| **1** | **逐特徵正規化移到 LSTM 之前**（主幹與跳接共用同一個 BN_F） | 塌縮源自輸入尺度；主幹目前吃的是 rank-1.00，跳接吃的是 rank-1.88 | 輸入秩 1.00 → 1.88，整條主幹（LSTM / GAT / projection）第一次拿到可分辨的橫截面；GATv2 的注意力應開始非均勻 | 一個旗標，3+7 種子 |
| 2 | **加寬預測頭 / 改 per-target 讀出**（每檔一個 32→1 向量，1,600 參數） | ReLU 已是唯一在製造秩的主幹運算子（1.10 → 1.57）；而探針是 per-target 且達 +0.0754，共享 head 只有 +0.0439 | 縮小 58% 這個缺口 | 3+7 種子 |
| 3 | **改動 1 之後重測耦合層**（dense A、低秩 A、候選邊） | 目前候選邊無效是因為被乘的表示是 rank-1；若改動 1 讓 h_L1 的秩升高，同一組邊可能才開始有作用 | 若仍無效，則兩層邊設計確定被否證 | 3 種子 x 3 arm |
| 4 | **把候選邊寫成量測到的零結果** | — | IC 不變，改變論文主張 | 純分析 |

**降級的項目**：融合改拼接。理由不成立 —— 融合並未破壞秩（1.05 → 1.10），
拼接兩個 rank-1.05 與 rank-1.01 的近同向表示拿不到什麼。

**上限與否證條件**

- 架構層的改動上限是耦合點的 **+0.0754**，不是 +0.10 的線性高原。
  要碰到高原必須改編碼器或改輸入，不是改耦合。
- 若改動 1 讓秩升高但 IC 不動，瓶頸就在資料而非架構，
  下一步轉向外生變數與把 y 拆成隔夜跳空 + 盤中。

**口試用的一句話**

> Two operators in this model create cross-sectional rank: a BatchNorm inside
> the skip connection, and the ReLU in the prediction head. Neither belongs to
> the multiplex architecture. That is the finding, and it is what the next
> round of experiments is built on.

## 6. 「F3 + 拼接式跳接」要怎麼寫進簡報

以下是可直接照抄的內容。順序即建議的製作順序。

### 6.1 Notations（p12 Model 區塊補三列）

| Category | Notation | Description | Property |
|---|---|---|---|
| Model | `F′` | Number of features actually fed to the encoder (`feature_subset`) | Input |
| Model | `d_raw` | Width of the raw-skip path, `d_raw = F′` | Input |
| Model | `d_proj` | Projection output width, `d′ = d_proj + d_raw` | Input |
| Model | `S₁ ∈ R^{d_raw×F′}` | Raw-skip weight, no bias | Variable |
| Model | `r₁ᵢ(t) ∈ R^{d_raw}` | Raw-skip output of US node i | Variable |

並把既有的 `d′` 描述改成
`Shared latent dimension after projection and skip concatenation`。

`BN_F(·)` 需要一句定義（放在 p15 或註腳）：

> `BN_F` normalises **within a feature, across nodes** — the BatchNorm axis.
> LayerNorm normalises within a node across features; at `F′ = 3` that leaves
> one degree of freedom per node and deletes the cross-section.

### 6.2 p15 Phase 1：一條式子取代 Step 1/2/3

主式：

```
h₁ᵢ(t) = [ LayerNorm( GELU( P₁ · z₁ᵢ(t) ) ) ; S₁ · BN_F( x₁ᵢ(t)[T] ) ]  ∈ R^{d′}
           \___________ 29 dims ___________/   \______ 3 dims ______/
```

Algorithm 1 改動（原第 7 行拆成兩行）：

```
Input:  ... ; projections P₁, P₂; raw-skip S₁; feature-wise norm BN_F
Output: latent states h₁ ∈ R^{n₁×d′}, h₂ ∈ R^{n₂×d′}, d′ = d_proj + d_raw

6:  z₁ ← GAT₁(s₁, E₁, ω₁);  z₂ ← GAT₂(s₂, E₂, ω₂)
7:  r₁ ← S₁ · BN_F(X₁[:, T])                        ▷ raw skip, no bias
8:  h₁ ← [ LayerNorm(GELU(P₁ · z₁)) ; r₁ ]          ▷ concat, d′ = 29 + 3
9:  h₂ ← LayerNorm(GELU(P₂ · z₂))
10: return h₁, h₂
```

三個標註方塊（沿用現行版式）改成：`Temporal encoding` / `Graph` /
`Type-specific projection + raw skip`。

### 6.3 p14 流程圖

已產出 `docs/figures/magnet_flow_v3.svg`，可直接匯入取代現行圖。與 v2 的差異：

- 新增琥珀色 `Raw skip` 直通方塊，從 L1 輸入旁路到 concat
- ADR Projection 標 `29 dims`，新增 `concat → d′ = 29 + 3 = 32` 橫條
- 三個線性探針數字標在對應位置（`+0.0874` / `+0.0754` / `+0.0439`）

- 圖例：琥珀色 = new in MAGNET-v2

### 6.4 新增一頁：`Why the encoder needs a bypass`

這是本工作唯一站得住的貢獻，值得一整頁。建議放在 Phase 1 之後。

**The projected representation is the same vector for every US node**

| Representation | cosine between the 30 US nodes | ridge probe test IC |
|---|---:|---:|
| raw 3 features (30 × 3) | — | +0.0874 |
| projected 29 dims | **+0.99997** (min +0.9998) | +0.0448 |
| projected 29 + skip 3 | +0.9921 | +0.0754 |
| model output | — | +0.0439 |

> The 3 skip dimensions carry 1.3% of the energy at the coupling point and
> essentially all of the cross-sectional information.

**The normaliser is the mechanism, not a detail**

| Normaliser | normalises | probe test IC |
|---|---|---:|
| none | — | +0.0874 |
| LayerNorm (feature axis) | within a node, across features | **+0.0311** |
| feature-wise (node axis) | within a feature, across nodes | **+0.0874** |

At `F′ = 3`, LayerNorm leaves one degree of freedom per node. Two earlier
versions of this experiment used it and were invalidated. `none` is
information-preserving but ill-conditioned in the linear layer (feature scales
differ by 5,000x), so the feature-wise normaliser is the one that works.

**Result (10 seeds each, matched seed set)**

| Metric | w/o skip | with skip | Δ | Welch | Paired t | Mann-Whitney | Wilcoxon | Wins |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| IC | +0.0248 | +0.0439 | +0.0191 | 0.008 | 0.025 | 0.009 | 0.049 | 8/10 |
| RankIC | +0.0345 | +0.0515 | +0.0170 | 0.003 | 0.017 | 0.007 | 0.037 | 7/10 |

Selected on validation IC: +0.0313 → +0.0653, paired p = 0.0002, 10 of 10 seeds.

### 6.5 p22 環境設定補列

Data & Model 表加 `F′ = 3`、`d_proj = 29`、`d_raw = 3`、`L_GAT = 1`、`T_ρ = 60`、
`λ = 0`。「Setting for MAGNET」下的三行改成四行：

**這四行放在一起才是誠實的呈現**：前兩項是先驗與精簡的選擇，第三項才是

### 6.6 p6 Contribution 與 p23 結果表

## 10. 「把融合移到前面」的實驗紀錄（回應口試 Q7）

教授上次建議的 early fusion 方向**已經實作過**，架構名稱是
`magnet_intermediate`（`src/models/magnet_intermediate.py`），不是
`baseline_early_fusion`（後者是輸入層直接拼接 ADR 特徵，屬對照組）。
該檔 docstring 第一行即註明「回應口試 Q7」。

### 10.1 它改了什麼

現行 MAGNET 是 **late fusion** —— 台股圖跑在融合**之前**：

```
h_gat_L2 = GAT_L2(h_lstm_L2, E2)        台股圖在這裡就用完了
h_fused  = g·h1_{p(j)} + (1-g)·h_L2     ADR 到這裡才進來，逐節點
y_hat    = head(h_fused)                之後沒有任何傳播
```

台股圖消耗的是只含台股特徵的表示，等 ADR 資訊抵達時圖已經用完。
當時量到的後果（`magnet_intermediate.py` 檔頭）：

```
擾動整個 x_seq_L1 後 y_hat 的變動
    配對 7 檔     mean|Δ| = 2.07e-02
    無配對 43 檔  mean|Δ| = 0.00e+00      <- 位元零
```

是**結構性的零**：不存在前向路徑，連梯度路徑都沒有。這個缺陷在 k=7 的
舊 universe 不可能被發現（7 檔全部有配對）。

`magnet_intermediate` 只改一件事，把融合移到 L2 圖傳播之前：

```
z_L2   = proj_L2(h_lstm_L2)             注意：圖之前
h_seed = g·ẑ_L1 + (1-g)·z_L2
h_prop = GAT_L2(h_seed, E2)             <- 圖現在載著跨市場資訊
h_out  = (1-a)·h_prop + a·h_seed        initial residual（APPNP teleport）
```

### 10.3 為什麼不佳

**主因：可達性修好了，但傳播把橫截面訊號攤平。**

當時的量測（`magnet_intermediate.py` 的 `__init__` 註解）：

> 融合提前之後 43 檔無配對台股確實有反應了，但 IC 反而沒有改善，
> 配對 7 檔從 +0.0418 掉到 −0.0063。節點間離散度：
>
> ```
> 傳播前 h_seed   std/mean = 2.5041
> 傳播後 h_out    std/mean = 0.2889      掉 8.7 倍
> ```
>
> L2 圖平均入度 17.1、GAT 兩層，聚合把跨市場訊號從橫截面成分攤成
> 共同成分——而 IC 只讀橫截面。

2026-08-18 用有效秩重新量到同一件事（`tw50chk_imed`，test split）：

| 位置 | 橫截面有效秩 |
|---|---:|
| 融合後 h_seed | **1.502** |
| L2 傳播後 h_prop | **1.257** |

**GAT_L2 的聚合在把秩往下壓。** 一個節點的 17 個鄰居平均下來，表示互相
拉近——就是圖卷積的 over-smoothing，只是排序任務的代價特別高，因為 IC
讀的正是節點之間的差異。

**佐證：residual 掃描是單調的，最佳點是「完全不做傳播」。**

```
α = 0     +0.0041
α = 0.25  +0.0083
α = 0.5   +0.0100
α = 0.75  +0.0106
α = 1.0   +0.0124     <- 最佳
```

`α = 1.0` 的意思是 `h_out = h_seed`，GAT_L2 的輸出被完全丟棄。
**這個實驗自己的超參掃描給出的結論是：台股圖的傳播步驟是純負擔。**
另外量到 α=1.0 時 `h_prop` 的有效秩是 **1.000**，傳播輸出完全塌成一個
方向，難怪丟掉比較好。三個 α 設定下 gate 都在 0.49~0.50，不是模型
關掉了跨市場通道。

**公平性但書：** 融合維度由 d′=32 變成 H=64，型別投影的輸出維度跟著改，
所以參數量與 late fusion 不同，做架構比較時必須揭露。因為結果是全面
變差而非變好，這個但書不改變結論方向。

### 10.4 與現行診斷是同一件事

| 位置 | 有效秩 |

| ĥ₁ 耦合後（台股側） | 1.05 |

intermediate 在 L2 傳播那一步掉（1.50 -> 1.26）。移動融合位置沒有解決
問題，只是換一個地方掉。

### 11.4 建議 7 — 「在各自表徵做 fusion 拼接」：已量測

**這一項可以在訓練之前就先量。** 用 per-target ridge 探針（協定同
`ridge_ladder`：同一組 walk-forward 索引、alpha 只在 val 的橫截面 IC 上選）
直接打在凍結的表示上，得到的是「一個線性讀出層最多能抽出多少」，
也就是任何下游頭的上界。

| 表示 | 維度 | 有效秩 | val IC | test IC |
|---|---:|---:|---:|---:|
| h₂ 單獨（台股側） | 32 | 1.005 | +0.0400 | +0.0190 |
| ĥ₁ 單獨（耦合後的美股側） | 32 | 1.054 | +0.1163 | +0.0862 |
| **gated fusion（現行）** | 32 | 1.096 | **+0.1166** | +0.0880 |
| **concat [ĥ₁ ; h₂]（建議 7）** | 64 | 1.091 | +0.1099 | **+0.0909** |
| concat，兩個 block 等能量 | 64 | **1.715** | +0.1099 | +0.0909 |
| concat 在投影之前 [GAT64 ; h₂] | 96 | — | +0.0691 | +0.0659 |

三件事：

**(1) 拼接與 gate 在探針上分不出來。** test 上 concat 高 0.0029，
但 **val 上 concat 反而低 0.0067** —— 而 val 才是我們的選模準則。
兩個方向不一致 = 落在雜訊內。

**(2) 拼接沒有把秩拉起來，原因是能量差 157 倍。**
橫截面置中後，ĥ₁ 佔總能量 **99.37%**，h₂ 只有 **0.63%**。
兩個 block 的主方向其實**幾乎正交**（|cos(PC1, PC1)| = 0.139），
h₂ 確實指向一個新方向 —— 但它太小，拼接後在熵加權下被淹沒。
把 h₂ 放大 16.9 倍到等能量，有效秩立刻從 1.09 跳到 **1.715**。

**(3) 但秩拉起來之後，探針一格也沒動。** 等能量版的 val/test 與原版
**完全相同**（+0.1099 / +0.0909）—— ridge 本來就對每一維標準化，
縮放對它是恆等變換。新增的那些方向來自 h₂，而 h₂ 單獨只值 **+0.0190**。

**(4) 第二種讀法（在投影之前拼接）明顯更差**：+0.0659 vs +0.0909。
投影層是有在做事的，把融合往前搬會賠掉它 —— 與 §10 `magnet_intermediate`
的結論一致。

**該不該跑？該。** 探針量的是「凍結表示 + 線性讀出」，而真的用 concat
訓練會學出不同的 h₂ —— 探針是先驗，不是判決。而且成本低：

```yaml
model:
  fusion:
    mode: concat          # 新鍵，預設 gate，既有 run 不受影響
```

- `CrossLayerFusion.forward` 在 concat 模式回傳 `torch.cat([h_L1, h_L2], -1)`
- `build_model` 把 `PredictionHead` 的輸入維度改成 `2 * d_prime`

- 參數量幾乎不變：head 第一層 32→64 變 64→64（+2,048），
  gate_mlp 64→32（2,080）消失

**先驗是「打平」**，所以這一項要當作**檢定**而不是改善來報告 ——
若真的贏了，贏的是「訓練出來的 h₂ 不一樣」，那是個比 IC 更有意思的發現。

### 11.5 建議 8 — 理論優先，以及一個必須先講的修正

這一點我們其實已經在做 —— 秩的帳（§9.1）就是理論側的診斷，
三個 next step 都是從它推出來的，不是補洞。但 §11.4 的量測
**修正了本文件先前的一個過度簡化說法**，報告前必須改口：

> **先前的說法**：橫截面有效秩塌到 1 是瓶頸，把秩拉起來就會好。
>
> **量到的事實**：等能量拼接把秩從 1.09 拉到 1.715，
> 探針 IC **一格都沒動**（+0.0909 → +0.0909）。

正確的表述是：

- **秩是必要條件，不是目標函數。** 有效秩 = 1 代表 50 檔股票的表示全部
  落在同一條直線上，那每天只能排出同一種順序 —— 這是**致命的**，
  所以秩 ≈ 1 可以直接判死。
- 但秩 > 1 **不保證**新增的方向會預測。h₂ 貢獻了一個近乎正交的新方向，
  它自己只值 +0.0190，所以拼進來也只把 +0.0862 抬到 +0.0909。
- 所以診斷要**成對地讀**：秩負責篩掉不可能的設計，
  探針負責回答剩下的設計值多少。單看任一個都會做錯決定。

這個修正讓論證變**強**不變弱，而且正好是建議 8 要的東西：
先量、找出機制、再改，而不是看到 43 檔無配對台股「碰不到」就去補一條邊
（§10 的 `magnet_intermediate` 就是那樣做的，可達性修好了，IC 掉到 +0.0030）。

**理論側目前站得住的三句話**：

1. 任何把節點表示平均在一起的算子都會消掉排序需要的橫截面差異 ——
   耦合（1.69 → 1.05）、L2 傳播（1.502 → 1.257）、稠密 A、cs_demean
   全部敗在這一條。
2. 目前只有兩個算子在製造秩，**兩個都不屬於多層設計**：
   跳接裡的逐特徵正規化（1.00 → 1.88）與預測頭的 ReLU（1.10 → 1.57）。
3. 架構層的天花板是耦合點的 **+0.0754**，不是 +0.10 的線性高原。
   要碰到高原得換輸入或換編碼器，不是換耦合方式。

**可證偽的條件**（口試值得主動講）：若三個 next step 都做完，
秩上去了但 IC 沒上去，那瓶頸就是資料而不是架構 ——
這個結論本身也是結果，不是失敗。

## 12. 回應建議 8 的核心質疑：跳接是不是在補洞？（2026-08-22）

教授的原意：**新增的特徵拼接屬於補破洞的一環，理論上原先未拼接的
編碼設計就應該足夠。**

結論先講：**這個質疑成立，而且量測結果比質疑本身更不利於我們。**
但「理論上應該足夠」這句話要拆成兩件事——**表達能力**與**可最佳化性**。
編碼器在前者上確實足夠，壞的是後者，而且壞在哪裡可以精確指出來。

---

### 12.1 編碼器實際吃到什麼（訓練期，30 檔美股 × 1,150 天）

`data/features/` 沒有任何正規化，`MultiplexDataset` 也沒有，
所以 LSTM 吃到的是原始尺度：

| 特徵 | mean | std | min | max |
|---|---:|---:|---:|---:|
| log_return | 0.0009 | **0.0245** | −0.228 | 0.235 |
| RSI_14 | 53.3564 | **11.5374** | 11.674 | 92.176 |
| BB_pos | 0.5626 | 0.3236 | −0.405 | 1.529 |

- std 比值 **471 倍**，變異數比值 **222,302 倍**
- 輸入共變異數矩陣特徵值 `[4.97e-4, 2.18e-2, 133.2]`，
  條件數 **κ = 2.68e5**；逐特徵正規化後降到 **20.1**
- 橫截面有效秩 **1.0019**，節點間平均餘弦 **+0.999988**
  （逐特徵正規化後 → **1.8835**）

也就是說：**進入編碼器的那一刻，30 檔美股的特徵向量幾乎就是
「RSI 乘一個共同方向」**。編碼器沒有弄壞任何東西，它忠實地傳遞了
一個秩為 1 的輸入。

---

### 12.2 為什麼「理論上夠」在這裡不成立

LSTM 的第一個運算是 `W_ih · x`。原則上 `W_ih` 可以自己學出逐特徵縮放
（把 RSI 那一行縮小 471 倍），所以**表達能力沒有問題**。
問題在最佳化，有兩層機制，兩層都量到了。

**(a) 初始化時閘門就飽和。**
`W_ih ~ U(±1/√64)`，RSI 進入閘門的量級是 `|W[:,RSI]| × std = 13.85`：

| 輸入 | 平均 \|z\| | \|z\| > 4 的比例 | 平均 σ′(z) |
|---|---:|---:|---:|
| 原始尺度 | 3.48 ~ 3.74 | **37% ~ 44%** | **0.055 ~ 0.072** |
| 逐特徵正規化 | 0.13 | **0.0%** | **0.248**（健康上限 0.25） |

近四成的閘門一開始就落在 sigmoid 的平坦區，梯度先被衰減 **4 倍**。
Adam 對此**幫不上忙**——它正規化的是步長，不是曲率；
真實梯度接近零時，Adam 只會把噪音放大。

**(b) 逃離飽和的唯一出路，會順便殺掉帶訊號的那個特徵。**
模型確實逃出來了（訓練後 |z|>4 只剩 0.2%），但逃法是**把輸入權重整行縮小**。
而 weight_decay = **0.001** 大於 log_return 方向上的資料曲率 **0.000497**——
在那個方向上，**正則化項比資料本身更有力**。
以 ridge 的收縮因子 `s/(s+λ)` 估計：

| 方向 | 曲率 s | s/(s+λ) |
|---|---:|---:|
| log_return | 4.97e-4 | **0.33** |
| BB_pos | 2.18e-2 | 0.956 |
| RSI_14 | 133.2 | 0.99999 |

再加上 `torch.optim.Adam` 用的是 **L2-in-gradient 而非解耦的 AdamW**，
衰減項也會被 Adam 的分母除過，對真實梯度接近零的參數等於一個
**固定大小的往零推的步伐**。兩者疊加，實測比 0.33 嚴重得多。

---

### 12.3 十顆種子的直接證據

訓練後 `W_ih` 逐特徵的行範數（初始化時三行都約 1.15）：

| | log_return | RSI_14 | BB_pos |
|---|---:|---:|---:|
| 無跳接（10 顆種子中位數） | **0.0213** | 0.3607 | 0.0718 |
| 有跳接（10 顆種子中位數） | **0.0070** | 0.3226 | 0.0465 |

換算成實際進入閘門的量級（`|W| × std`）：

```
RSI_14 : BB_pos : log_return  =  4.15 : 0.023 : 0.00052  =  8000 : 45 : 1
```

**主幹編碼器其實是一個只看 RSI 的編碼器。**
有沒有跳接都一樣——無跳接時 log_return 的權重也塌到 0.021。
（須揭露：種子變異很大，10 顆裡有 2 顆把 log_return 留在 0.67 附近；
但 8/10 低於 0.16，而 RSI 永遠是最大的那一行。）

有跳接時主幹反而縮得更兇（0.0070 < 0.0213），這很合理——
跳接已經在載 log_return，主幹更沒有理由留著它。

---

### 12.4 關鍵推論：跳接的功勞不在「繞過」，在「正規化」

跳接的結構是 `BN_F(x) → Linear(3→3, no bias)`。
那個 `Linear` 是秩 ≤ 3 的無偏映射，**創造不了任何資訊**。
所以跳接帶進來的東西全部來自 `BN_F`——而 `_FeatureNorm`
是**整個模型裡唯一一處逐特徵跨節點的正規化**
（`proj` 裡的 LayerNorm 是逐節點跨特徵，方向相反，實測把探針從
+0.0874 壓到 +0.0311）。

於是正確的因果不是

> 編碼器會破壞資訊 → 所以需要一條旁路繞過它

而是

> **輸入沒有做逐特徵正規化 → 編碼器在飽和區起步、被 weight decay
> 殺掉小尺度特徵 → 跳接因為自帶 BN_F 而意外成為全模型唯一
> 有正規化的路徑。**

**所以教授是對的：這是補洞。而且洞不在架構，在前處理。**

---

### 12.5 這個質疑把 next step 第一項變成一個決定性實驗

原本的 next step 第一項是「把逐特徵正規化移到 LSTM 之前」。
接受教授的質疑之後，它不再只是一個改善，而是一個**可證偽的檢定**：

| 結果 | 解讀 |
|---|---|
| BN_F 移到 LSTM 輸入後，**跳接不再增加任何東西** | **教授完全正確**。跳接是前處理缺陷的補償，不是架構貢獻。論文中降級為實作細節，不列為 contribution |
| 移到輸入後，**跳接仍有額外增益** | 存在真正的旁路效應（編碼器即使在良好條件下仍有損失），這時才有資格把跳接當成架構主張，而且必須解釋清楚它繞過了什麼 |

配套要一起跑的三個對照（都很便宜）：

1. `BN_F` 於 LSTM 輸入 + **無跳接** ← 主檢定
2. `BN_F` 於 LSTM 輸入 + 有跳接 ← 增量是否為零
3. 1. 再加 `AdamW`（解耦 weight decay）← 分離「正規化」與「衰減耦合」兩個機制

**我的先驗是第一列會成立**，理由是 §12.1–12.3 的五項量測指向同一個機制。
若如此，簡報要主動改口，不要等被問。

| 對照：正規化前跳接的增量 `T1F3rb -> T1F3bnl1` | +0.0234 | **0.0014** | **0.0026** | 8/10 | 兩者皆顯著 |
| 機制：AdamW `arm1 -> arm3` | +0.0058 | 0.4359 | **0.0429** | 7/10 | 僅跨種子顯著 |

**結論：教授的質疑成立。**

跳接的增量從 **+0.0234（逐日與跨種子雙雙通過 Holm）**
掉到 **+0.0060（兩個檢定都不顯著，且低於跨種子 MDE 0.0082）**。
一個原本是本專案唯一雙重顯著的架構改善，在修好前處理之後變成偵測不到。

**但措辭要精準**：這是「無結論」，不是「證實無效」——
+0.0060 落在偵測門檻以下，不代表它是 0。論文中兩者不可互換。

`T1F3rb -> arm1` 的逐日檢定不顯著，是因為 `r_day` 只有 0.24：
兩個 arm 是獨立訓練的不同編碼器，逐日 IC 序列相關低，配對消不掉噪音
（對照組 `T1F3rb -> T1F3bnl1` 的 `r_day` 是 0.80，那是同一顆網路加一條路徑）。
這是 `paired_daily` 說明文字裡已經寫明的情況，不是證據薄弱。

### 13.6 對簡報的影響

**要改的：**

1. **跳接不能再當作 contribution。** 它在 IC 上的效果由前處理缺陷造成，
   修好之後偵測不到。改寫成「診斷發現」——我們找出了機制，
   這是誠實且仍有價值的貢獻，但不是架構貢獻。
2. **p23 的主結果**要決定用哪一個 arm。建議 `arm3`：IC 與 EF 打平、
   種子變異小 8.6 倍、結構最簡單。代價是放棄 RankIC 勝過 EF 的宣稱——

3. **不可以說**「MAGNET 的多層耦合有效」。四個設定在 IC 上打平，

**新增的可宣稱項：**

> 我們定位出一個具體、可量測、且被三組對照獨立確認的失效機制：
> 未正規化的輸入使 LSTM 在飽和區起步（4 成閘門 |z| > 4），
> 而 `torch.optim.Adam` 的 L2-in-gradient 衰減在 log_return 方向上
> 強過資料曲率（1e-3 vs 4.97e-4），最終讓主幹退化成只看 RSI 的編碼器
> （進入閘門的量級相差 7,960 倍）。修正之後 test IC 由 +0.0241
> 升到 +0.0459（跨種子 Holm p < 0.0001，9/10 顆種子較優）。

### 14.1 有沒有提升——有，但要看跟誰比

## 18. 各層獨立的輸入正規化：一個有界的 null（2026-08-23）

`input_norm` 放在 `SharedLSTM.forward` 裡，而 `self.lstm` 在 MAGNET 的
forward 中被呼叫兩次，所以**兩層都有正規化**——但共用同一個模組實例，
running stats 與 affine 參數是兩個市場合併的。

新增 `model.lstm.input_norm_scope`（`shared` 預設 / `per_layer`），
`SharedLSTM.forward` 加 `layer: int = 0`，MAGNET 對 L2 傳 `layer=1`。
模組名 `input_norm` 不變，既有 checkpoint 的鍵不受影響
（arm3 重評仍 +0.0517、`max_abs_delta_IC = 0.0000`，221 測試全過）。
其餘 15 個呼叫 `SharedLSTM` 的 baseline 都只呼叫一次，吃預設 `layer=0`。

### 18.1 結果（10 顆種子，同種子配對）

| 指標 | shared | per_layer | Δ | 95% CI | 配對 t | 勝 |
|---|---:|---:|---:|---|---:|---:|
| IC | +0.0517 (sd 0.0021) | +0.0513 (sd 0.0027) | −0.0004 | [−0.0023, +0.0015] | 0.6177 | 5/10 |
| RankIC | +0.0351 (sd 0.0049) | +0.0350 (sd 0.0049) | −0.0002 | [−0.0058, +0.0054] | 0.9507 | 4/10 |

### 18.2 這是一個「操作確實生效」的 null

正規化之後各市場的 std（理想 = 1.0）：

| scope | US | TW | 市場間最大比值 |
|---|---|---|---:|
| `shared` | 1.4071 / 1.1287 / 1.0940 | 0.9197 / 1.1827 / 1.0916 | **1.53x** |
| `per_layer` | 1.1528 / 1.1776 / 1.1043 | 1.0396 / 1.1211 / 1.0584 | **1.11x** |

殘餘尺度差確實被消掉了（1.53x -> 1.11x），而 IC 一動也沒動。
**這比「無結論」強**：CI 是 [−0.0023, +0.0015]，整段都落在 10 顆種子的
MDE 0.0082 之內，所以可以下界定的結論——
移除那 1.53 倍殘餘的效果小於 ±0.0023。

### 18.3 論文可用的一句話

把 §13 與本節放在一起，得到一個有上下界的敏感度陳述：

```
特徵之間 471x 的尺度差   ->  IC +0.0219   (Holm p < 0.0001, 9/10 seeds)
市場之間 1.53x 的尺度差  ->  IC -0.0004   (CI [-0.0023, +0.0015], 5/10)
```

**問題出在「量級」而不是「有沒有正規化」。** 三個數量級的差距是致命的，
1.5 倍不是。這比只說「輸入正規化很重要」精確得多，也回答了
「那要正規化到多細」這個實作問題：以層為單位切開沒有必要。

### 18.4 決定

**主結果 arm 維持 `tw50_inbnw_noskip`（shared）。**
`per_layer` 的 IC 低 0.0004、種子 sd 反而略高（0.0027 vs 0.0021），
沒有理由換；而且 `shared` 與「兩層共用 LSTM 權重」的設計主張一致。
`input_norm_scope` 保留為旋鈕與這一節的證據。

## 19. F=1 的結果：耦合是一個「均化器」，而秩的敘事必須修正（2026-08-24）

### 19.1 完整的 F 掃描（10 顆種子，CPU）

| arm | val IC | test IC | sd | RankIC |
|---|---:|---:|---:|---:|

但逐日檢定（唯一能外推到新期間的）給的是**無結論**：
HAC p = 0.5549、Holm 1.0000、MDE 0.0118 > 效果量 0.0024。

**F1 / F3 / F9 三者在逐日層級全部分不出來。** F 掃描到此結案。

須揭露：**若照方法學把特徵集選在 val 上，會選到 F1（10/10 勝），
而 F1 的 test 較低。** val 對這個設計決策沒有預測力，
這也是「約 50 組設定」那個公平性缺口的具體例證。

### 19.2 為什麼 F 不重要：耦合把不同品質的輸入拉成一樣

同協定的 per-target ridge 探針（seed 42）：

| | 輸入正規化後的秩 | h_L1 秩 | ĥ₁ 秩 | **h_L1 探針** | **ĥ₁ 探針** |
|---|---:|---:|---:|---:|---:|
| F1 | **1.0000** | 1.023 | 1.028 | **+0.0955** | **+0.0579** |
| F3 | 1.9296 | 1.534 | 1.053 | +0.0822 | +0.0586 |

**兩個輸入品質差 16% 抵達耦合點，離開時完全相同。**
耦合吃掉 F1 的 39%、F3 的 29%，把兩者都壓到 +0.058。

這是耦合作為瓶頸的**第二條獨立證據**（第一條是 §17.1 的資訊階梯），
而且解釋了整個 F 掃描為何全是 null：**餵什麼進去都會被耦合削到同一個水準。**

### 19.3 必須修正：秩不追蹤可抽取的資訊

先前 §12.6 / §14 的說法是：

> 有效秩 = 1 代表 50 檔股票的表示全部落在同一條直線上，
> 那每天只能排出同一種順序。

**這是錯的。** 若 X_t（n x d）秩為 1，則 X_t = u_t v_tᵀ，
線性讀出給出的排序由 u_t 決定，而 **u_t 每天都不同**——
秩 1 完全支援逐日變動的排序。秩 1 真正限制的是
「所有線性讀出給出的排序相同（至多差一個符號）」，
不是「排序不能變」。

實測也推翻了它：**F1 的表示秩 1.023，探針值 +0.0955；
F3 的秩 1.534，探針值 +0.0822。秩低的那個資訊反而多。**

正確的說法：

- **秩是描述性的，不是資訊量的代理。** 要問「這裡還剩多少可用資訊」，
  就用探針量，不要用秩推。
- 先前用秩推導出來的結論中，**凡是被探針獨立確認過的仍然成立**
  （輸入尺度問題 -> §13 的 +0.0219、耦合是瓶頸 -> §17.1 與本節），
  **凡是只靠秩推的都要撤回**（「秩 1 不能排序」、
  「拼接會提升因為秩會升」、「per-target head 因為 ReLU 造秩所以值得做」）。
- §11.4 的等能量拼接結果（秩 1.09 -> 1.72、探針一格未動）
  當時已經指向這個結論，本節把它坐實。

### 19.4 對規劃的影響

- **F 掃描結案**，主結果維持 F3（逐日無差異，F3 是既有設定，不換）
- **耦合的地位再升一級**：兩條獨立證據都指向它，而且它是「均化器」——
  這解釋了為何 F、跳接、候選邊、dense A 全部無效
- **§17.5 第 2 順位的 2c（43 檔無配對台股）仍是核心**，但現在要重新表述：
  問題不只是那 43 檔拿不到訊號，而是**耦合這個算子本身把 +0.095 削到 +0.058**
- **秩的敘事要從 p24 撤下**，改用探針的資訊階梯。後者每一格都是直接量的，
  不需要中介推論

## 21. 43 檔無配對台股：這不是路由問題，是因子暴露問題（2026-08-24）

從理論下手的第一步是問「跨市場訊號的內在維度是多少」。這決定了架構該長什麼樣。

### 21.1 量到的事實一：跨市場訊號幾乎是一維的

把最好的線性 baseline（R2，每檔台股一個 30 維美股暴露向量）按自由度拆開，
同協定、同分割、alpha 只在 val 上選：

| 設定 | 每日自由度 | val IC | **test IC** | 佔完整 R2 |
|---|---:|---:|---:|---:|
| 完整 R2（30 檔美股報酬） | 30 | +0.1558 | **+0.1020** | 100% |
| rank-10（前十個主成分） | 10 | +0.1355 | +0.0821 | 80% |
| **rank-3（前三個主成分）** | 3 | +0.1520 | **+0.0887** | **87%** |
| **rank-1（等權市場報酬）** | **1** | +0.1317 | **+0.0738** | **72%** |
| rank-1（第一主成分） | 1 | +0.1342 | +0.0743 | 73% |

**每天從美股取一個純量、每檔台股配一個純量 beta，就拿到最好線性 baseline 的 72%。**
三個自由度拿到 87%。**跨市場訊號的內在維度是 1 到 3，不是 30。**

### 21.2 量到的事實二：兩條路徑的差別是量級，不是機制

h_L1 的共同 / 特異分解（30 檔美股，246 天）：

| | 範數 | 佔能量 |
|---|---:|---:|
| 共同成分 c | 5.6125 | 99.86% |
| 特異成分 δ | 0.2125 | **0.14%** |

| 路徑 | 共同 | 特異 | 特異/共同 |
|---|---:|---:|---:|
| 恆等邊（7 檔） | 5.6125 | 0.3363 | **0.0599** |
| 候選邊（50 檔） | 0.003869 | 0.000194 | **0.0501** |

**兩條路徑帶過去的成分比例幾乎一樣（0.060 vs 0.050）**——
候選邊沒有「把訊號攤平」，它只是**整體小 1,450 倍**（B 欄範數中位數 0.000697）。

（先前推測「平均 30 個會把特異成分衰減 √30」——**這個推測被量測推翻**，
衰減是 1,735 倍而不是 5.5 倍，而且共同成分被衰減同樣多。）

### 21.3 理論結論：問題被誤診了

把兩件事放在一起：

- 跨市場訊號 72% 是「一個每日純量 × 每檔一個 beta」
- 候選邊的實際功能形式是 `Σᵢ B[i,j] h₁ᵢ ≈ (Σᵢ B[i,j]) · c(t)`
  = **`colsum_j × 市場因子(t)`**

**候選邊的函數形式本來就是 beta 模型，`colsum_j` 就是 β_j。**
它失敗不是因為形式錯，是因為 `colsum_j × |c|` 的量級是 0.0039，
而恆等邊給 7 檔的是 5.6125 —— **相差 1,450 倍，在相加之後等於不存在。**

所以：

> **43 檔缺的不是「一個美股對應」，而是「拿得到市場因子」。**
> 恆等邊之所以有效，不是因為「同一家公司」這件事特別，
> 而是因為它把 c(t) 以**滿量級**交給那 7 檔。43 檔拿到的是同一個 c(t)，
> 量級 1/1450。

這也解釋了為什麼所有嘗試都失敗：候選邊、dense A、`magnet_intermediate`、
`magnet_weak_industry`（2026-07 跑過，IC **+0.0020**）——
全部都在設計「更好的兩兩對應」，而訊號根本不在兩兩對應裡。

### 21.4 一個明確的檢定目標

| | test IC |
|---|---:|
| rank-1 beta 模型（每檔一個純量） | **+0.0738** |
| 我們的耦合點 ĥ₁ 探針（32 維，per-target） | +0.0586 |
| 我們的模型輸出 | +0.0517 |

**我們 32 維的學習表示，用 per-target 讀出，輸給「一個純量（美股市場報酬）」
的 per-target 讀出。** 差 +0.0152。而模型輸出離 rank-1 beta 有 **+0.0221**——
比本專案至今任何一次改善都大。

**所以下一步的成功判準不是「比 EF 好」，是「至少追上一個一參數的 beta 模型」。**

### 21.5 依理論強度排序的三個架構修正

**修正 1（最直接、理論最乾淨）：讓每檔台股都以滿量級拿到市場因子。**

```
現行    ĥ₁ⱼ = h₁_p(j)·[paired] + Σᵢ B[i,j] h₁ᵢ
提議    ĥ₁ⱼ = h₁_p(j)·[paired] + γ_j · h̄₁ + Σᵢ B[i,j] (h₁ᵢ − h̄₁)
```

- `γ_j`（每檔一個純量，50 個參數）**初始化為 1**——
  一開始就等於「每檔都拿到滿量級的市場因子」，訓練只需要調整暴露
- 第三項是**去掉共同成分之後**的殘差聚合，這才是圖結構該做的事
- 理論保證：`γ_j` 這一項單獨就是 rank-1 beta 模型，所以下界是 +0.0738
  （若訓練後低於這個數，問題在下游的 gate 或 head，不在耦合）
- 成本：50 個參數 + 一個旗標

**修正 2：把因子維度從 1 開到 3。**

rank-3 拿到 87%（+0.0887 vs rank-1 的 +0.0738）。做法是讓 `h̄₁` 換成
美股側的前 k 個主方向（k=3），每檔台股一個 k 維暴露向量：

```
ĥ₁ⱼ = h₁_p(j)·[paired] + Σ_{m=1..3} Γ[j,m] · u_m(t) + 殘差項
```

`u_m(t)` 可以是 h₁ 的當日 top-k 奇異向量（可微），或直接學 k 個共享的
投影方向。參數 50×3 = 150。

**修正 3（若 1 與 2 有效才做）：殘差項才用圖。**

只有在共同成分被獨立處理之後，`Σᵢ B[i,j](h₁ᵢ − h̄₁)` 才可能有作用——
現在的 B 是在跟共同成分競爭同一個通道。這一項的上限是
完整 R2 減去 rank-3，即 +0.1020 − 0.0887 = **+0.0133**。

### 21.6 這對「multiplex GNN」這個框架的意義（要誠實面對）

若修正 1 就拿到大部分，那結論是：

> 跨市場訊號是低維的因子暴露，不是個股之間的網路關係。
> 一個 50 參數的 beta 層勝過 1,493 條學習出來的邊。

這會削弱「多層圖」作為方法論主張的正當性。但這是資料說的，
而且它本身是一個**可發表的負面結果**——
文獻中的跨市場 GNN（MEIG、MAN-SF、HATS、DeltaLag）都假設個股層級的關係，
我們有直接證據說在這個問題上那個假設不成立：
**72% 的訊號用一個每日純量就拿到了。**

反過來說，若修正 1 拿到 +0.0738 之後**還有剩餘空間**能被修正 3 收回，
那圖結構的正當性才第一次有量化的支持。兩種結果都值得寫。

## 22. 恆等邊與候選邊的結構缺陷（2026-08-24）

前向反事實（10 顆種子，同種子配對；模型未在這些設定下訓練，故為指示性）：

| 設定 | IC | Δ vs full | 佔跨市場總價值 |
|---|---:|---:|---:|
| **full** | **+0.0517** | — | 100% |
| 恆等邊改成美股均值 h̄₁（7 檔） | +0.0334 | −0.0183 | **60%** |
| 恆等邊改成隨機一檔美股（7 檔） | +0.0270 | −0.0247 | **45%** |
| 43 檔補上 h̄₁、7 檔保留自己的 | +0.0359 | −0.0158 | 65% |
| 全部 50 檔都給 h̄₁ | **+0.0036** | −0.0481 | **≈ 0%** |
| 無跨市場 | +0.0065 | −0.0452 | 0% |

量級（test 平均）：恆等項 5.6104、h̄₁ 5.5907、h₂ 5.6272、**候選項 0.004183**。

---

### 缺陷 1：橫截面度量消掉共同成分，而耦合輸出 99.86% 是共同成分

IC 是**橫截面**的：對所有股票加同一個向量，排序不變。
所以跨市場通道只能透過**股票之間的差異**影響 IC。

而耦合送出去的東西 99.86% 是共同成分 c(t)。恆等邊給 7 檔 5.6104、
給 43 檔 0.004183——**唯一的跨股票差異是「有沒有配對」這個二元分組**，
乘上 c(t) 的每日大小。

實測把這個拆開了：

- 恆等邊改成 h̄₁ 仍保留 **60%** 的跨市場價值
  -> 這 60% 是「二元分組 × 市場因子」，**不是 ADR 對應**
- 改成隨機一檔美股仍保留 **45%**
- 真正屬於「這一檔 ADR 特有」的只有 **40%**

**恆等邊有效，但主要不是因為它接的是同一家公司。**
它實質上是一個兩級的 beta 模型：7 檔 beta ≈ 1、43 檔 beta ≈ 0。
p8 的 H1 把增益歸給公司層級連結，只有四成成立。

---

### 缺陷 2：兩條路徑相加，量級差 1,345 倍，下游無從分辨

`ĥ₁ⱼ = identity + candidate`。相加之後，下游看到的是單一向量，
無法區分「這是滿量級的 ADR 訊號」與「這是 1/1345 的加權平均」。

後果是 50 檔台股被分成兩個完全不同的量級régime（5.61 vs 0.004），
而**讀出層是共享的**。任何對其中一組合適的權重，對另一組都是錯的。

**模型裡沒有任何機制可以權衡 identity 與 candidate。**
兩者的相對比重完全由 B 的量級決定，而 B 的量級是優化器在缺陷 3
的不對稱壓力下決定的。

---

### 缺陷 3：正則化對兩條路徑不對稱

> **2026-08-24：本節的機制是錯的，已由 §24.1 更正。**
> `weak_beta` 初始化是 `torch.zeros`——B 從 0 長起來，不是被壓下去的；
> weight decay 在 3,600 步只造成 0.36% 衰減，解釋不了任何事。
> 真正的缺陷是**冷啟動不對稱**，見 §24.1。以下保留為修改紀錄。


| 路徑 | 參數 | 受 weight decay |
|---|---|---|
| 恆等邊 | 無（權重固定為 1） | **否** |
| 候選邊 | `weak_beta` 30x50 | **是** |

`weight_decay = 1e-3`，而 AdamW 的解耦衰減對梯度接近零的參數
是一個固定大小往零推的步伐。實測 `|B|max` 由 0.0167（Adam）
掉到 **0.000513**（AdamW），縮 32 倍。

**這是設計層的不對稱，不是調參問題**：一條路徑豁免於正則化，
另一條被懲罰，而兩者競爭同一個加法通道。

---

### 缺陷 4：gate 在量級塌陷的下游，結構上救不了

`h_f = g ⊙ ĥ₁ + (1−g) ⊙ h₂`。對無配對的 43 檔，
`‖ĥ₁‖ = 0.0042`、`‖h₂‖ = 5.6272`——**相差 1,345 倍**。

即使 `g = 1`（完全採用跨市場側），能引入的也只有 0.0042。
gate 的位置在量級塌陷之後，**它沒有槓桿**。

實測 g ≈ 0.513、跨節點 sd 0.0071，先前被解讀為「gate 沒學會分化」；
正確的解讀是**它無事可分化**。

---

### 缺陷 5：B 是靜態的，而 A₁/A₂ 每天重建

設計哲學不一致：層內邊由 60 天相關窗每日重建，
層間邊卻是一個學一次的靜態矩陣。加上恆等權重固定為 1，
**整個跨層結構是時間不變的**。

於是跨市場通道的每日變化完全來自 h₁(t) 本身——
而 h₁(t) 有 99.86% 的能量在單一共同方向上。
**通道的每日自由度結構上約等於 1。**

（§21 顯示訊號本身也是 1~3 維，所以容量不是綁住的那一環，
量級才是。這一點要說清楚，否則會誤導成「要加寬通道」。）

---

### 缺陷 6：把因子平均分給所有人，等於沒給

這是反事實裡最違反直覺、也最有理論價值的一格：

> **全部 50 檔都給 h̄₁ -> IC +0.0036，幾乎歸零。**

原因是 IC 的橫截面性質：所有股票加上同一個向量，排序完全不變。
`γ_j · h̄₁` 只有在 **γ_j 隨 j 變動**時才有貢獻。

**這推翻了 §21.5 修正 1 的初始化設計。**
我提議「`γ_j` 初始化為 1，一開始就等於每檔都拿到滿量級的市場因子」——
但 γ_j 全部等於 1 正好是退化情形，初始貢獻**恰好是零**，
不是「立即拿到 +0.0738」。

正確的設計必須讓 γ_j **一開始就分散**（例如用訓練期各檔對美股市場的
實際 beta 初始化，或隨機初始化後靠 rank loss 驅動）。
rank-1 beta 模型之所以值 +0.0738，全部來自 **β_j 的跨股票離散度**，
不是來自市場因子本身。

---

### 綜合：一句話的理論診斷

> 跨市場通道只能透過股票之間的差異影響橫截面排序，
> 但現行設計送出去的東西 99.86% 是所有股票共同的市場因子。
> 唯一的跨股票差異來自「有沒有 ADR 配對」這個**二元、時間不變**的分組
> （佔跨市場價值的 60%），以及 7 檔的 ADR 特異成分（40%）。
> 候選邊本應提供連續的 beta 分散度，但它被正則化不對稱壓到 1/1345，
> 而 gate 位於這個塌陷的下游，無法補救。

須注意 `43 檔補上 h̄₁` 的反事實是 **−0.0158（變差）**。
模型並未在該設定下訓練，下游的 gate 與 head 從未見過那個量級，
所以這不能當成「修正 1 無效」的證據——但它是一個警告：
**光補量級而不同時處理 γ_j 的離散度，方向是錯的。**

### 23.1 恆等邊與候選邊的問題具體怎麼解

| # | 修正 | 對應缺陷 | 成本 | 依據 |
|---|---|---|---|---|
| ~~A~~ | ~~`weak_beta` 排除 weight decay~~ | ~~3~~ | — | **已作廢，見 §24.1**：weight decay 在 3,600 步只衰減 0.36%，這個修正幾乎不會有任何效果 |

但那是對 h_L1（30 檔美股）在壞掉的條件數下做的，且它同時抽掉了恆等路徑的
共同成分。這裡是對耦合**輸出**、在 50 檔台股上去均值，是不同的算子。
仍應視為高風險項，排在 A/B 之後。

**執行順序：A -> B -> (C+D 一起) -> E。**
A 必須最先，否則 B 新增的 γ_j 會被同一個不對稱壓力壓掉。

### 23.2 重新設計後的修正 1 能帶來什麼

**與原提議的差別**只有一處，但那一處決定成敗：

| | 原提議（§21.5） | 重新設計 |
|---|---|---|
| γ_j 初始化 | **全部 = 1** | **一開始就分散** |
| 初始貢獻 | **恰好 0**（實測 `mean to all 50` = +0.0036） | 非零 |

原提議把「每檔都拿到滿量級市場因子」當成好事，但 IC 是橫截面的——
**所有股票加同一個向量，排序完全不變**。價值全部在 γ_j 的**離散度**，
不在因子本身。

**可期待的效益，附上界與下界：**

| | test IC | 相對現況 |
|---|---:|---:|
| 現況（主結果 arm） | +0.0517 | — |
| **rank-1 beta（目標）** | **+0.0738** | **+0.0221** |
| rank-3 beta（開到 3 個因子） | +0.0887 | +0.0370 |
| 完整 R2（30 維，上限） | +0.1020 | +0.0503 |

**+0.0221 比本專案至今任何一次改善都大**（輸入正規化是 +0.0219，
拼接跳接是 +0.0234 且已被證實是前處理缺陷）。

**三個理論保證：**

1. **共享讀出層對這個機制是足夠的。**
   `γ_j · h̄₁(t)` 經過共享線性讀出 w 得到 `γ_j · (w·h̄₁(t))` = γ_j x 每日純量——
   **這正是 rank-1 beta 模型的函數形式**，不需要 per-target head。
   （對照：耦合點的 per-target 探針只有 +0.0586，仍輸給 +0.0738，
   所以問題不在讀出層是不是 per-target。）
2. **下界是不變差**：γ 可以學到 0 而退化回現況——**前提是先做修正 A**，
   否則 weight decay 會把 γ 也一起壓掉。
3. **它取代而非疊加**：§22 量到恆等邊 60% 的價值是「有沒有配對」這個
   二元分組 x 市場因子。beta 層把它從 **2 級升級成 50 級連續**，
   所以是同一個機制的推廣，不是多接一條路。

**風險**：`43 檔補上 h̄₁` 的前向反事實是 **−0.0158**。
模型未在該設定下訓練，不能當否證，但它說明**量級與離散度必須同時處理**，
分開做會更差。

### 23.4 「恆等邊改為可學習權重」的順位

**應該往前，但不該當成獨立實驗——它和 beta 層是同一件事。**

現行：7 檔配對的恆等權重**全部固定為 1**，所以那 7 檔對市場因子的
暴露完全相同，**彼此之間沒有任何跨股票差異**。而 §22 量到
恆等邊 60% 的價值來自「配對 vs 無配對」這個二元分組——
也就是說，**現行設計只用到 1 個位元的 beta 資訊**。

把恆等權重改成可學的 α_j（7 個參數），效果是讓那 7 檔有**不同的 beta**。
把同一個想法推廣到 50 檔（無配對者的權重作用在 h̄₁ 而非特定 ADR），
**得到的就是 beta 層**。兩者是同一個機制的窄版與寬版：

```
現行          ĥ₁ⱼ = 1 · h₁_p(j) · [paired]
可學恆等權重   ĥ₁ⱼ = α_j · h₁_p(j) · [paired]              (7 個參數)
beta 層       ĥ₁ⱼ = α_j · h₁_p(j) · [paired] + γ_j · h̄₁    (7 + 50 個參數)
```

**所以建議直接跳到 beta 層**，把可學恆等權重當成它的一部分實作，
不要分兩次跑。

**但有一個順序上的陷阱**：若**單獨**把恆等權重改成可學而不先做修正 A，
那條原本豁免於 weight decay 的路徑會第一次被正則化——
**很可能把唯一有效的路徑也一起壓掉**。這是 §22 缺陷 3 的直接推論。

**結論：順位往前（併入新第 1 順位），但必須排在修正 A 之後。**

## 24. 更正與待修正順位總表（2026-08-24）

### 24.1 更正 §22 缺陷 3：是冷啟動，不是正則化

**查核的起點**：`weak_beta` 到底受哪些正則化。結果發現兩件事，
其中第二件推翻了先前的歸因。

**(a) 目前沒有任何 weight decay 的排除設定。**
`train.py` 只有一個 param group，所有參數（含 `weak_beta`）吃同一個
`weight_decay = 1e-3`。

**(b) 先前移除的 `lambda_sparse` 是另一個通道，不要混為一談。**

| | `lambda_sparse` | `weight_decay` |
|---|---|---|
| 形式 | L1，加在 loss 裡（`loss + λ·‖B ⊙ M‖₁`） | L2 / 解耦，在優化器裡 |
| 預設 | 1e-3 | 1e-3 |
| 目前值 | **0**（`magnet_weak_free` 移除） | **1e-3**（仍作用在 `weak_beta`） |
| 目的 | 選邊（稀疏先驗） | 一般正則化 |

移除理由記在程式註解：「lambda=1e-3 已證實會把邊凍住」——
與下面的冷啟動分析一致（L1 在 0 點的次梯度會把參數釘在 0）。

**(c) 更正：先前把「\|B\|max 0.0167 -> 0.000513」歸給 AdamW 的解耦衰減，
那是錯誤歸因。**

`weak_beta` 的初始化是 **`torch.zeros`**——B 從 0 長起來，不是被壓下去。

| arm | 優化器 | best_epoch | \|B\|max |
|---|---|---:|---:|
| `tw50_inbn_noskip` | adam | 3.0 | **0.000443** |
| `tw50_inbnw_noskip` | adamw | 11.5 | **0.000513** |
| `tw50_T1F3bnl1` | adam | 10.5 | 0.016684 |

兩個 `input_norm` arm 的 \|B\| 幾乎相同（0.00044 vs 0.00051），
**差別不在優化器**；0.0167 那個屬於不同架構（有跳接、無 `input_norm`）。

而且 weight decay 在量級上不可能造成它：

| 步數 | 保留比例 | 衰減 |
|---:|---:|---:|
| 360 | 0.999640 | 0.036% |
| 3,600 | 0.996406 | **0.359%** |

**(d) 正確的缺陷 3：飽和加法通道中的冷啟動不對稱。**

| 路徑 | 初始值 | 可學 |
|---|---|---|
| 恆等邊 | **權重 = 1（滿量級）** | 否，固定 |
| 候選邊 | **B = 0（完全關閉）** | 是 |

第 0 步時跨市場通道是 100% 恆等、0% 候選。B 必須從恰好零長起來，而且

- 對 7 檔配對股，恆等路徑**已經以滿量級送出同一個共同成分**，B 的邊際梯度極小
- 對 43 檔無配對，B 是唯一路徑，但輸出進入一個 h₂ 大 1,345 倍的加法通道，
  而 gate 與共享 head 早已適應「那一側送來 ≈ 0」

實測終點 \|B\|max ≈ 0.0005 說的是：**梯度從來沒有正當化把它長大。**

### 24.2 由此推出的統一設計原則

更正之後，所有修正提議收斂到同一條原則：

> **任何耦合路徑，若其輸出對 50 檔台股是同一個向量，
> 對橫截面 IC 的貢獻恰好為零——不論量級多大。**

三個初始化的對照，全部都是零貢獻：

| 初始化 | 跨股票是否分散 | 初始貢獻 | 實測 |
|---|---|---|---|
| `B = 0`（現行） | — | 0（量級為零） | \|B\| 終點 0.0005 |
| `B[i,j] = 1/n₁` 均勻 | **否** | **0（跨股票相同）** | **`mean to all 50` = +0.0036** |
| `γ_j = 1` 全部（§21.5 原提議） | **否** | **0** | 同上 |
| **跨股票分散** | **是** | 非零 | 待測 |

`B[i,j] = 1/30` 對所有 i,j 會讓候選路徑送出 `h̄₁`（範數 5.59，滿量級）——
但那正是實測 +0.0036 的那一格。**光補量級不夠，必須補離散度。**

這條原則同時解釋了三件先前分開看的事：候選邊為何長不大、
`γ_j = 1` 的提議為何是退化情形、以及恆等邊的 60% 價值為何是
「有沒有配對」這個**二元分散**而非配對本身。

1. **我們追平了線性高原，沒有超越。** 與 R2 差 −0.0009、與 KTW+ 差 −0.0066。

2. **機制是市場 beta，也就是文獻裡早就知道的主導因子。**

   新的跨市場結構，是**終於把已知的主導因子接進架構裡**。

### 26.2 三個結論

**(1) ③ 的貢獻是 ① 的 2.5 倍（+0.0179 vs +0.0073）。**

③ 用的就是那 1,493 條候選邊。在 beta 層之前它們**可證明是惰性的**——
去候選邊 ΔIC = **+0.0000**（p = 0.69，§17.3）。同一組邊，現在是單項最大貢獻者。

機制在 §22 已經推出來：候選邊之前被要求搬運共同成分，而那個通道已經被
量級大 1,345 倍的恆等路徑佔滿；現在 B 只乘殘差 `h₁ᵢ − h̄₁`，共同成分由 γ
獨立承擔，B 第一次在做它被設計來做的事。

**這是本專案第一次有量化證據支持跨層邊。** 但措辭要精確——
有貢獻的是**跨層的候選邊 B**，不是層內由相關係數建的 A₁/A₂，
後者仍未單獨消融。

**(2) ② 單獨在架構裡達到 +0.0716，對照獨立線性模型的 +0.0738。**

差 −0.0022，遠在該 arm 的 sd 0.0223 之內。
**架構沒有扯後腿**——§23.2 推論「共享讀出層對 beta 機制是足夠的」得到驗證。

**(3) ① 與 ③ 除了加 IC，還大幅穩定種子變異。**

| 設定 | sd |
|---|---:|
| 完整 | **0.0042** |
| 關 ① | 0.0058 |
| 關 ③ | 0.0133 |
| 只有 ② | **0.0223** |

只有 ② 時 sd 是完整版的 **5.3 倍**。

順帶一個異常值得記錄：**關 ① 的 val IC 與完整版幾乎相同
（+0.1420 vs +0.1421），test 卻低 0.0073。** ① 帶來的是泛化增益，
在 val 上看不出來——這又是一個 val 對設計決策沒有預測力的例子（同 §19.1）。

## 28. 層內圖 A₁ / A₂ 的消融（2026-08-25）

跨層邊已在 §26 消融過；層內由 |rho| > 0.3 建的相關係數圖，這是第一次單獨檢驗。
四個 arm 各 10 顆種子，種子集合對齊，CPU，`max_abs_delta_IC = 0.0000`。

**兩種消融各回答不同問題**：

- `empty` 只留 self-loop——保留 GAT 的全部參數，只切斷鄰居。
  比「繞過 GAT」乾淨，後者會同時少掉一批參數，混淆兩件事。
- `rand` 保留邊數與 `edge_attr` 的值分布，只重抽端點（固定 seed，逐快照不同）。

```

逐日 Holm 0.0272   跨種子 Holm 0.0000   隨機較優 0/10
```

**錯誤的鄰居會主動傷害**——在錯的結構上做訊息傳遞等於注入噪音。
所以相關係數挑出來的結構**確實帶有資訊**。

精確的措辭是：**相關係數圖顯著優於隨機圖（+0.0181，雙重顯著），
但只略優於完全不用圖（+0.0054，僅跨種子顯著）。**
兩句話都要講，只講其中一句都會誤導。

**(3) 拿掉台股層的圖，IC 掉但 RankIC 反而升。**

A₂ 只留 self-loop：IC −0.0050（跨種子 p 0.0961）、RankIC **+0.0045**（8/10 顆種子）。
兩個指標方向相反，且逐日檢定都是無結論。目前**沒有機制解釋**，列為 open observation。

### 29.4a 更正：per-stock 的 α_j / γ_j **沒有被識別**（2026-08-26）

29.4 初稿把 seed 42 的 `γ[2330] = +0.8052` 與 `γ[2454] = +0.1678` 當成

10 顆種子的 `γ[2330]`：

```

+0.0220  −0.0730  −0.0353  −0.1948  −0.2085      mean +0.0259, sd 0.3394
```

**只有 4/10 顆種子 `γ[2330] > 0`，也只有 4/10 顆 `γ[2330] > γ[2454]`。**
以 10 顆種子的平均看，2454 的 γ（+0.174）反而**高於** 2330（+0.026）。

整個向量都不穩定：

| | 跨種子 \|Spearman\| mean | \|r\| < 0.2 的種子對 | 隨機基準 |
|---|---:|---:|---:|
| γ | 0.195 | 60% | 0.116（95th pct 0.293） |
| α | 0.141 | 73% | 同上 |

α 基本上落在隨機基準上。這**不是符號翻轉造成的**——若是，\|Spearman\|
會接近 1，實測只有 0.195。

**成因**：`γ_j · h̄₁` 裡的 `h̄₁` 是 32 維向量，方向由該顆種子的

**可以說**：模型需要「50 個自由暴露」的**容量**——拿掉它（只留 ②）
掉到 +0.0716、sd 變成 5.3 倍。

**不可以說**：任何單一 `γ_j` 或 `α_j` 的數值、排序、正負，
或「哪一檔的市場暴露比較高」。單顆種子的參數不能當經濟量解讀。

這一格必須主動講。教授問「那你學到的 beta 是多少」是必然會出現的問題，

**階梯翻轉了，這是本頁的重點。**

新 arm 單調遞增到 h_f，只在讀出層掉 6%。

> 量測一致性警告：本次輸入格量到 +0.0874，§20 記的是 +0.0828（不同腳本，差 0.0046）。
> **簡報只能用同一次量測的一整條，不可混用兩個來源。**

## 30. 怎麼向教授講解現在的 MAGNET（2026-08-26）

### 30.0 講解前要先解決的框架問題

現在的架構與原本的命名和動機已經不是同一件事。量到的貢獻是：

| 元件 | 貢獻 | 原本簡報的地位 |
|---|---:|---|
| 跨層三條路徑 | **+0.0295** | 「two-tier 邊」 |
| 層內相關係數圖（A₁/A₂） | +0.0054 | 「multiplex 的核心」 |
| ADR 恆等路徑（①） | +0.0073 | **整篇論文的動機** |

如果開場說「這是一個 multiplex GNN」，第一個問題就會是
「那圖的貢獻在哪裡」，而正確答案是 5%。framing 當場崩掉。

**要用的 framing**：這是一個**從量測推導出來的最小結構**。
先量跨市場訊號長什麼樣子，再設計剛好能承載它的結構，然後逐項消融。
貢獻是「歸因」，不是「發明一個新的 GNN」。

這個 framing 同時正面回應教授建議 8（不要急著補破洞，從理論下手）——
因為它就是照那句話做出來的。

### 30.1 五塊白板（主線，約 8 分鐘）

**板 1 — 問題**

> 昨夜美股收盤到今天台股開盤中間有 5 小時，沒有重疊。
> 這段時間的美股資訊，對今天台股 50 檔的**排序**能說什麼？

**板 2 — 先量，再設計**

30 檔美股前一日報酬做 per-target ridge：**+0.1020**。
把它做秩分解：

```
全 30 維          +0.1020
rank-3            +0.0887   （87%）
rank-1 等權市場因子 +0.0738   （72%）
```

> 這個通道基本上是 `y_j ≈ β_j · m(t) + ε_j`：
> **每天一個純量，每檔一個載荷。** 它不是一個路由問題。

**板 3 — 舊架構實際上算了什麼**（這是關鍵的一塊）

```
ĥ₁ⱼ = h₁,p(j) + Σᵢ B[i,j] · h₁ᵢ
```

兩個量到的事實：

- h₁ **99.86% 是共同成分**（|c| 5.6125 vs |δ| 0.2125）
  → `h₁,p(j) ≈ h̄₁`，配到哪一檔幾乎不影響
- 恆等路徑送 **5.6104** 給 7 檔，候選路徑送 **0.004183** 給 43 檔
  → 差 **1,345 倍**

> 所以舊架構等價於強制 **β_j 只能取兩個值：配對 = 1、無配對 = 0。**

這一行同時解釋掉先前**所有**的 null 結果：

| 先前的 null | 解釋 |
|---|---|
| 去候選邊 ΔIC 恰為 **+0.0000**（p = 0.69） | 額外的邊進入一個已飽和的通道 |
| F1 / F3 / F9 逐日 Holm 全 1.0000 | 耦合把輸入品質差異抹平 |
| 稠密耦合 A 無效 | 同上 |
| 拼接式融合無增益 | 同上 |

**板 4 — 修正：不是三個設計選擇，是一個分解的三個項**

```
h₁ᵢ = h̄₁ + (h₁ᵢ − h̄₁)          共同 + 特異

ĥ₁ⱼ = α_j·h₁,p(j)·[paired] + γ_j·h̄₁ + Σᵢ B[i,j]·(h₁ᵢ − h̄₁)
      ① ADR 特異（7 檔）        ② 因子暴露（50 檔）   ③ 殘差結構
```

只加 **100 個參數**（α, γ ∈ R⁵⁰），佔總參數 **0.2%**。
**test IC +0.0517 → +0.1011。**

> γ 拿走共同成分之後，B 第一次只承載殘差——
> 它不再跟一個大 1,345 倍的通道搶同一條線。

**板 5 — 消融驗證每一項**

| 拿掉 | Δ IC | 較優種子 |
|---|---:|---:|
| ① ADR 恆等 | −0.0073 | 1/10 |
| ③ 殘差聚合 | **−0.0179** | 0/10 |
| ①+③ | −0.0295 | 0/10 |

> ③ 用的就是先前**可證明惰性**的那 1,493 條候選邊。
> 同一組邊，現在是單項最大貢獻者。

### 30.2 四件要**主動講**、不要等被問的事

不主動講，被問到就變成防守；主動講，就是研究誠實度。

**(1) 追平，不是超越。**
+0.1011 vs R2 +0.1020、KTW+ +0.1077。機制是市場 beta，文獻早就知道。
貢獻是「把已知的主導因子正確接進架構」與「量化各元件」，
不是發現新的跨市場結構。

**(2) 層內圖只值 +0.0054，逐日 Holm = 1.0000。**
但同密度隨機圖會掉 **−0.0181**（逐日 0.0272、跨種子 0.0000，雙重顯著）。
**兩句一定要一起講**：相關係數圖顯著優於隨機圖，但只略優於完全不用圖。

**(3) ADR 恆等路徑是三條裡最小的。**
而且反事實顯示：恆等邊 **60% 的價值來自「有沒有配對」的二元分組，
只有 40% 是 ADR 特有**。動機仍然成立——它是發現 β 被兩級化的入口——
但**主張要降級**。

**(4) per-stock 的 α_j / γ_j 沒有被識別。**（見 §29.4a）
跨種子 |Spearman| γ 0.195 / α 0.141，隨機基準 0.116。
可以說「模型需要 50 個自由暴露的**容量**」；
**不可以說**「2330 的市場暴露是 0.81」。

## 31. 三階段架構的逐 Phase 講稿（2026-08-26）

給口試/週報用的講稿骨架。目標不是把 9 頁講完，是讓老師在 10 分鐘內
接受「這一版改了什麼、為什麼那樣改、憑什麼相信」。

**這一版真正的新增只有兩處**：Phase 1 的輸入正規化、Phase 2 的 beta 層。
Phase 3 只有 AdamW。**講稿的重量要照這個比例分配**，不要平均分給三個 Phase。

### 31.1 開場：先承認上週的質疑成立

> 上週老師說「拼接屬於補破洞，理論上原先未拼接的編碼設計就應該足夠」。
> 我們照這個方向查下去，結論是**老師是對的**。破洞不在編碼器的容量，
> 在它的輸入尺度。修好之後跳接就沒有價值了，這一版把它拿掉。
> 拿掉之後，才看得到真正的結構缺陷在 Phase 2——
> 而那個缺陷也不是缺模組，是一個**既有權重的參數化方式錯了**。

這段的作用是把「補洞 vs 從理論下手」這個方法論爭議一次結清，
後面才有籌碼講第二件事。

### 31.2 Phase 1 的新增：LSTM 前的逐特徵正規化

**一句話**：LSTM 的閘門是 sigmoid，輸入尺度直接決定它有沒有飽和。

三個數字講完診斷：

| | |
|---|---|
| RSI_14 的 std 是 log_return 的 | **471 倍** |
| 初始化時 \|z\| > 4 的閘門比例 | **37–44%**（該處 σ′(z) 剩 0.06，健康值 0.25） |
| 訓練完 W_ih 列範數 RSI : BB_pos : log_return | **8000 : 45 : 1** |

最後一列是關鍵：**主幹已經退化成一個只看 RSI 的編碼器。**
這不是調參問題，是條件數問題（κ(Cov) 2.68e5 → 正規化後 20.1）。

修正效果：**+0.0219**（10 種子、9/10 勝、跨種子 Holm p < 0.0001）。

**然後直接回答老師**：修好之後，跳接的增量由 +0.0234（當時雙重顯著）
掉到 **+0.0060（兩個檢定都不顯著）**。

> 一個「有效」的模組，在缺陷修好之後就不再有效，
> 那它原本就不是模組，是補丁。

### 31.3 Phase 2 的新增：beta 層（四拍講完，**不要在台上推導**）

聽眾要在 90 秒內抓到的只有一件事：
**每一檔台股對美股的敏感度不一樣。舊架構容得下這件事，
但實際上只學出了「配對的拿到 1、其餘的拿到 0 附近」。**

推導版本移到 §31.10，只在被追問時用。台上講下面四拍。

---

**第 1 拍 — 舊架構有這個自由度，但它學不起來**

先講清楚，否則會被抓到：**舊架構是有候選邊的**。恆等邊只接 7 檔，
但候選邊讓每一檔美股都可以連到每一檔台股。所以**架構上，
每一檔台股本來就可以有自己的敏感度**。

問題是它學不起來。把 `ĥ₁ⱼ = [配對]·h₁,p(j) + Σᵢ B[i,j]·h₁ᵢ` 拆開，
每一檔實際拿到的敏感度就是 `[配對] + colsum_j(B)`。實測（2025-04-10，seed 42）：

| arm | 配對的 7 檔 | 無配對的 43 檔 | 倍數 | \|B\|max |
|---|---:|---:|---:|---:|
| MAGNET-v2（8/19 主結果） | +1.0044 | +0.0139（sd 0.0923） | **72x** | 0.0181 |
| 輸入正規化（前一版主結果） | +1.0002 | **+0.0001**（sd 0.0008） | **12,295x** | 0.00038 |
| **beta 層（現行）** | +0.7143（sd 0.482） | **+0.0641**（sd 0.163） | **11x** | 0.842 |

兩件事要照實講：

1. **無配對的 43 檔不是結構上的 0。** MAGNET-v2 上它們拿到 +0.0139，
   而且彼此有差異（sd 0.0923）。**「只有 0 或 1」是錯的說法。**
2. **但它小到沒有作用。** 拿掉那 1,493 條候選邊，test IC 差 **+0.0000**（p = 0.69）。
   而且**架構愈修好，B 縮得愈小**——輸入正規化修好之後 \|B\|max 由 0.018 掉到 0.00038，
   到這一版之前，無配對組的敏感度是配對組的 **一萬兩千分之一**。

**為什麼學不起來？** 兩條路加進**同一個通道**。恆等邊一開始就滿載
（權重固定為 1，不用學），而它送的東西裡 **99.86% 是「美股大盤」**。
候選邊從 0 開始長，要學的是同一個大盤——
它在跟一個量級大上千倍、而且完全不需要學的東西競爭。

> **不是缺一條路，是既有的那條路被塞住了。**

這一格正好是老師說的「從理論下手」：如果架構真的缺一條路，
那修法就是加模組，就是補破洞；但架構不缺路，缺的是**讓那條路能用的條件**。
所以修法是把「大盤」從那個通道裡拿出來、給它自己一條路，
剩下的通道候選邊才有事做。

---

**第 2 拍 — 先量，證明重點是敏感度不是連線**

不用任何圖、不管哪檔連哪檔，只做一件最笨的事：
每天算一個數字「昨晚美股整體漲跌」，再給每檔台股一個自己的倍數。

**這樣就拿到全部跨市場資訊的 72%。**

> 所以問題不是「哪一檔美股連到哪一檔台股」，
> 是「每一檔台股該乘多少」。

---

**第 3 拍 — 修法：每檔一個旋鈕，訊號分三條路送**

美股那 30 檔的資訊，先拆成兩塊：**大家一起動的那塊**（美股大盤），
和**各自跟大盤差多少的那塊**（Nvidia 比大盤多漲 3%）。

然後分三條路送到台股：

| 路 | 誰收得到 | 送什麼 |
|---|---|---|
| ① 你的美國雙胞胎 | 7 檔 | ADR 自己的走勢——而且**現在可以自己決定聽多少**，以前是強制全聽 |
| ② 美股大盤 | **全部 50 檔** | 大盤 x 這一檔自己的敏感度 |
| ③ 個股偏離大盤的部分 | 全部 50 檔 | 走那些學出來的連線 |

多出來的只有每檔兩個旋鈕，共 **100 個參數，佔全模型 0.2%**。
IC 從 +0.0517 變成 **+0.1011**，大約翻倍。

擋「你只是加參數」的一句話：
**把這三條路的旋鈕轉到特定位置，模型就會變回舊的那個，輸出一模一樣。**
（有單元測試把關。所以不是換一個更大的模型，是把一個錯的限制拿掉。）

---

**第 4 拍 — 意外收穫：原本沒用的線，活了**

第三條路用的線，**一條都沒變**——數量一樣、位置一樣。
但改之前，把它們**全部拿掉，結果一模一樣**（IC 差 0.0000）。

為什麼？改之前這條路被要求搬「大盤」，
而大盤那個通道早就被第一條路塞爆了，它搬不動任何東西。
現在大盤交給第二條路，第三條路只要搬「偏離」——
它第一次派上用場，而且是三條路裡貢獻**最大**的
（+0.0179，是 ① 的 2.5 倍）。

> **同一組線，什麼都沒改，只是不再叫它做別人已經在做的事。**

（呼應第 1 拍：這條路一直都在，先前是被恆等邊塞住。）

---

**收尾用走查，一句話**

> 2330 學到的敏感度是 **0.81**，2454 是 **0.17**。
> 2454 以前是 0。0.17 不高，但它是**學出來的**，
> 不是因為沒在美國掛牌所以被強制設成 0。

### 31.10 備援：Phase 2 的推導版（只在被追問時用）

**第 1 步 — 先量跨市場訊號的維度。**
30 檔美股報酬對台股次日報酬做 per-target ridge，再做低秩截斷：

| | test IC | 佔比 |
|---|---:|---:|
| 全 30 維 | +0.1020 | 100% |
| rank-3 | +0.0887 | 87% |
| **rank-1（等權市場因子）** | **+0.0738** | **72%** |

結論：跨市場訊號主要是 `y_j ≈ β_j · m(t)`——
**每天一個市場純量，每檔一個暴露係數。**

**第 2 步 — 看舊架構對這件事的表達能力。**
h_L1 有 **99.86%** 是共同成分。寫成 `h₁ᵢ = h̄₁ + δᵢ`，舊的恆等邊給出：

```
有配對的 7 檔  :  ĥ₁ⱼ 拿到  h̄₁ + δ_p(j)
無配對的 43 檔 :  ĥ₁ⱼ 拿到  0
```

> **所以舊架構其實已經有一個 β，只是它只有兩級：配對 = 1、無配對 = 0。**

**第 3 步 — 這就是缺陷。**
要表示 50 個不同的 β，架構只給了兩級量化。
**不是缺邊，是既有邊的權重參數化錯了。**

**第 4 步 — 修法：把兩個成分拆開，各給一個逐檔係數。**

```
ĥ₁ⱼ = α_j · h₁,p(j) · [配對]  +  γ_j · h̄₁  +  Σᵢ B[i,j] · (h₁ᵢ − h̄₁)
      ① ADR 特異，7 檔           ② 市場因子暴露，50 檔   ③ 殘差結構
```

α、γ 各 50 個，共 **100 個參數，佔全模型 0.2%**（49,064）。

**第 5 步 — 主動說「舊架構是新架構的特例」。**
令 α = 1、γ_j = B 的第 j 欄和、B 不變，前向輸出**位元相同**——
有單元測試把關。所以這不是換一個更大的模型，
是**把一個錯的約束拿掉**。

**第 6 步 — 結果。**
IC +0.0517 → **+0.1011**、RankIC +0.0351 → **+0.0967**。
對前主結果、early fusion、MAGNET-v2 全部 **10/10 種子勝**，
且是本專案**第一次同時通過逐日與跨種子的 Holm 校正**。

**（備援續）Phase 2 的第二個發現：惰性的邊活了**

這一格比 IC 數字本身更值得講。

③ 的貢獻 **+0.0179**，是 ① 的 **2.5 倍**。而 ③ 用的就是那 1,493 條候選邊——
在 beta 層之前它們**可證明是惰性的**：去掉候選邊 ΔIC 恰為 **+0.0000**（p = 0.69）。

> **同一組邊，數量沒變、位置沒變，現在是單項最大貢獻者。**

機制：先前 B 被要求搬運共同成分，而那個通道已經被量級大 **1,345 倍**的
恆等路徑佔滿。現在共同成分由 γ 獨立承擔，B 只乘殘差，
第一次在做它被設計來做的事。

走查上直接看得到（2330，2025-04-10）：

| | 最強的三條 B 邊 |
|---|---|
| 舊版 | +.0181 / +.0178 / +.0170（全正，彼此幾乎無差） |
| **新版** | **+.2518 / −.2513 / +.2358**（大 14 倍，**開始有負號**） |

## 33. 回應教授質疑：②+③ 在數學上就是舊式嗎？（2026-08-26）

**質疑原文**：架構上 ②、③ 在數學本質上和原版的 `Σᵢ B_eff[i,j]·h₁ᵢ`
是一樣的東西，為什麼要把大盤和各檔股票分開？

**結論：質疑完全成立。而且這正是本工作的主張，不是對它的反駁。**

### 33.1 代數：教授是對的

```
②+③ = γ_j·h̄₁ + Σᵢ B[i,j]·(h₁ᵢ − h̄₁)
     = γ_j·h̄₁ + Σᵢ B[i,j]·h₁ᵢ − (Σᵢ B[i,j])·h̄₁
     = Σᵢ B[i,j]·h₁ᵢ + (γ_j − Σₖ B[k,j])·h̄₁              h̄₁ = (1/n₁)Σᵢ h₁ᵢ
     = Σᵢ [ B[i,j] + (γ_j − Σₖ B[k,j]) / n₁ ] · h₁ᵢ
     = Σᵢ B′[i,j] · h₁ᵢ                                    ← 就是舊式
```

數值驗證（主結果 checkpoint，seed 42）：

| 檢查 | 結果 |
|---|---|
| `②+③` vs `Σᵢ B′[i,j]·h₁ᵢ` | max\|diff\| **7.5e-07**（相對量級 10.26） |
| 單元測試 `test_beta_layer_is_a_reparametrisation` | 反方向（γ_j = colsum_j(B) 時退回舊式）已在 CI 把關 |

**函數空間完全相同。新版沒有增加任何表達能力。**
這件事我們自己在實作時就寫了測試，不是被問到才發現。

### 33.2 那為什麼要分開：改的是最佳化幾何，不是假設空間

**(a) B 有一個 50 維的零空間，γ 就是被舊式綁死、新式解放出來的那個座標。**

```
Σᵢ (B[i,j] + c)·(h₁ᵢ − h̄₁) = Σᵢ B[i,j]·(h₁ᵢ − h̄₁)      對任意常數 c
```
實測 max\|diff\| = 5.6e-05。**每一欄加常數不改變 ③。**

所以舊式裡「市場暴露」不是一個座標，是分散在 30 個座標上的一個**共同模態**。
要表示「每檔一個暴露 γ_j」，舊式必須讓一整欄 30 個參數**協同**移動到同一個值；
新式只要動 1 個。同一個函數，所需的協同程度差 30 倍。

**(b) 同一個參數同時乘兩塊量級差 28 倍的東西，等於共用一個學習率。**

| | \|h̄₁\| | \|h₁ᵢ − h̄₁\| | 比值 |
|---|---:|---:|---:|
| 舊 arm | 5.6152 | 0.2000 | **28.1x** |
| 新 arm | 5.3827 | 1.2701 | 4.2x |

舊式裡 `B[i,j]` 同時乘共同成分與殘差。它的梯度被大 28 倍的共同成分主導——
要學殘差載重，必須在一個對暴露方向敏感 28 倍的梯度裡擠出來。
**這是參數化的條件數問題**，和 §12 診斷出的輸入尺度問題是同一類毛病，
只是發生在耦合層而不是編碼器。

分開之後，γ 管大範數方向、B 管小範數方向，各有各的有效步長。

**(c) 舊式裡 B 還要跟恆等邊搶同一個方向。**

恆等邊以固定權重 1 把 h̄₁ 送給 7 檔、0 送給 43 檔。
B 要學的市場暴露，對那 7 檔是「已經有了、不要重複」、
對 43 檔是「從零長出來」。**同一組參數要同時滿足兩個相反的要求。**
α / γ / B 分開之後這個衝突消失。

### 33.3 決定性的實證：兩者都能表達彼此的解，但只有一個找得到

同樣的資料、同樣的步數、同樣的優化器、同樣的種子集合：

| | 收斂到 | test IC |
|---|---|---:|
| 舊參數化 | \|B\|max = **0.00038** | +0.0517 |
| 新參數化 | — | **+0.1011** |

而舊式的解在新式的參數空間裡（令 γ_j = colsum_j(B)），
新式的解也在舊式的參數空間裡（令 B′ 如 §33.1）。
**差別不在能不能表達，在梯度下降會不會走到那裡。**

### 33.4 這在文獻上是標準現象，而且有現成的例子

| 例子 | 是否增加表達能力 | 有人說它「本質上是同一個東西」嗎 |
|---|---|---|
| **殘差連接（ResNet）** | **否**——普通深層網路能表達的 ResNet 都能表達，反之亦然 | 沒有 |
| **BatchNorm** | **否**——推論時可完全吸收進權重，函數類不變 | 沒有 |
| **本工作的 beta 層** | **否**——§33.1 已證 | 這正是質疑 |

三者都屬於同一類：**重參數化改變梯度下降的隱含偏好（implicit bias），
不改變假設空間。** 這類改動的價值判準不是「能表達什麼」，
而是「同樣的訓練流程會收斂到哪裡」——而那是用實驗量的，§33.3 量了。

### 33.5 一個技術上的小差別（誠實補充）

`weak_mask` 把 B 在 7 個恆等位置歸零（1,500 格中的 7 格）。
新式的 ② 在所有 i 都貢獻 γ_j/n₁，**包括被遮蔽的位置**。
所以嚴格說，7 個配對欄各多出一個方向；**其餘 43 欄的函數空間完全相同**。
這是技術細節，不構成實質的容量差異——若有人主張效果來自這 7 個方向，
反證是：關掉 ①（ADR 路徑）只掉 −0.0073，而關掉 ③ 掉 −0.0179。

### 33.6 質疑合理嗎：合理，而且它逼出正確的主張

這是這個工作**最該被問的問題**。回答它之後，主張必須從

> ~~我們設計了一個新的跨市場耦合機制~~

改成

> **我們證明既有的耦合機制在原本的參數化下學不起來，找出了原因
> （共同成分與殘差共用參數、且與固定權重的恆等邊競爭同一方向），
> 並用一個不改變函數空間的重參數化解決它。**

新說法**更弱**，但**更準確**，而且**可檢驗**——
§33.1 的代數、§33.2 的三個機制、§33.3 的收斂對照，每一格都可以獨立複驗。

這也正面接上教授建議 8（不要急著補破洞，從理論下手）：
**這個改動加起來是 100 個參數、0 個新運算子、0 個新資訊來源。**
它不是補洞，是把既有的洞找出來並說明它為什麼堵著。

### 35.3 拆解：一個超可加的交互作用

### 35.4 這批實驗最有價值的產出：一條方法論更正

**§34 列的三個最大 headroom，全部沒有兌現：**

| headroom 的來源 | 預測 | 實得 | 差 |
|---|---:|---:|---:|
| 輸入端 ridge 探針（F3 +0.0874 -> F1 +0.1020） | +0.0146 | **+0.0030** | 1/5 |
| h_f 探針（讀出層 −6%） | +0.0066 | **−0.0093** | **反向** |
| 資料的低秩分解（rank-1 72% -> rank-3 87%） | +0.0149 | **−0.0005** | 0 |

各自的原因：

| # | 為什麼高估 |
|---|---|
| 輸入探針 | 非線性編碼器本來就補掉了維度膨脹的損失。實測編碼器淨貢獻 F3 **+0.0120** vs F1 +0.0023——它一直在做這件事 |
| h_f 探針 | 探針是 **alpha 選在 val 上的事後線性讀出**，自帶正則化；聯合訓練的 per-target head 沒有這個保護，種子 sd 由 0.0050 翻到 0.0111（過擬合） |
| 低秩分解 | ③ 的殘差聚合**已經在承載非 rank-1 的結構**，再給 ② 加因子是重複勞動 |

> **ridge 探針的缺口，是「一個有正則化的事後線性讀取器能抽出多少」的上界，
> 不是「訓練得到的模型還能拿到多少」的上界。低秩分解同理。**

**而唯一奏效的那一項，依據不是 headroom 估計，是同架構下的消融證據**
（§28 量到關掉 A₂ 讓 RankIC 升 +0.0045、8/10 種子）。

**§34 的階梯必須據此加註，不可再拿它當改善空間的估計。**

### 35.6 必須一併揭露：離散度進一步惡化

| arm | n | std(ŷ)/std(y) | MSE |
|---|---:|---:|---:|
| `tw50_inbnw_noskip`（前前版） | 10 | 0.473（收縮） | 0.00045 |
| `tw50_beta`（現主結果） | 10 | 1.693 | 0.00106 |
| F1 + 無 A₂ | 10 | 1.481 | 0.00091 |
| **F1 + 無 A₂ + rank 1.0（新最佳）** | 10 | **2.592** | **0.00204** |

與 §32 對 A1 的分析完全一致：**離散度是 rank 損失「有多有把握」的讀數**
（`softplus(−(ŷu−ŷv))` 只要排序大致正確，整體放大就能降低損失）。
把 rank 權重由 0.5 加到 1.0，等於把這個放大誘因加倍。

**IC / RankIC 對尺度免疫，排序的提升是真的；但 MSE 由 0.00106 再翻倍到 0.00204，
相對前前版是 4.5 倍。** 這個 arm 若要當主結果，
過度離散的揭露必須寫在結果表的第一條註腳，而不是附註。

**注意 F1 + 無 A₂ 這一格的離散度反而低於現主結果（1.481 vs 1.693）**——
若之後要在「排序」與「校準」之間取捨，它是一個中間選項。
